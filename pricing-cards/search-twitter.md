## 为什么免费

- 它能把 status ID、公开渲染器、网页归档、截图哈希、OCR 与证据等级串成一份可核验结果，显著减少手工搜索和误把摘要当原文的风险。
- 已有一个真实人物案例、10 项离线测试、一次双渲染器实时恢复与截图 SHA-256 回读，具备可展示的交付证据。
- 扣分项同样明确：公开搜索无法证明账号历史全量，FxTwitter、VXTwitter、Wayback 和 Common Crawl 都可能变化，开源源码也容易复制。
- 因此当前定位为高质量免费入口，用真实案例积累购买信心；托管索引、团队证据仓库、持续平台适配和人工核验不包含在免费交付里。

## 买家得到什么

买家得到三个可直接调用的流程：从文本或 HTML 建立候选清单、恢复已知公开 status ID、登记截图与 OCR 证据。结果明确区分 live original、archived original、embedded card、screenshot copy、media quote、media paraphrase 和 unrecovered，并禁止把公开搜索覆盖写成完整账号历史。

免费交付不包含 X 登录会话、绕过访问控制、托管搜索 API、持续监控、法律核验、事实真伪裁决或人工补齐所有截图。

## 渠道与推广

- 官网详情页以“找到原帖，也诚实说明哪些没有找到”为核心结果。
- 展示真实案例中的已知 ID 覆盖、双渲染器一致、Wayback 空壳和截图哈希四类证据。
- 后续若提供托管索引、批量监控、团队证据仓库或人工核验，再建立独立付费交付，不把这些能力暗示为当前免费版本已包含。

## 风险、假设与复评

- 使用风险：搜索索引遗漏、第三方渲染器失效、截图 OCR 歧义和公开内容的版权或隐私边界。
- 假设：常见任务能减少数小时手工查找与证据整理；维护成本主要来自上游变化而非本地运行。
- 证据缺口：官网安装转化、10 次外部真实使用、跨语言截图 OCR 基线和持续六个月的上游失效率。
- 复评触发：版本变化、10 次外部可回读使用、引入托管基础设施，或上游适配成本显著变化。
