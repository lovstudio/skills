# 品牌片尾 · Pricing Card

版本：0.2.0（目录 ID `logo-sting`、调用 ID `lov-logo-sting`）。价格：0 Credits，免费入口。
以 MIT 许可免费提供；它是 LovStudio 所有视频类 Skill 的默认片尾依赖，免费才能让公开用户装上这些 Skill 时片尾同样可用。

把品牌的官方 Logo SVG 做成一段卡拍的片尾：中心光点吸气内爆，Logo 笔画一拍一笔砸入，小节线上一帧负片，字标落定并扫过一道光，
随拍呼吸后硬切黑场；合成音效与画面读同一份帧表，每一击落在同一帧。片尾配置在共享 Profile 里登记一次，`media_end.py make`
一条命令生成，`media_end.py mix` 一条命令并进整片混音，所有视频 Skill 的成片都用同一段片尾。

提供 Logo 规格解析、卡拍帧表、确定性合成音效、Remotion 组件、四种画幅的独立片段渲染、共享片尾的生成与混音脚本和质检说明。
不包含 Logo 设计或重画、位图转矢量、其它动画风格的定制、整片剪辑与混音、平台发布，以及任何 Logo 素材本身。

真实用例都来自作者本人的成片：一部参考成片的片尾被抽成本 Skill，同一配置下的音效与原片逐字节一致；之后三部采访成片和一条口播样片用它收尾，
加入片尾后整片响度约 −16 LUFS、真峰值不高于 −3 dBTP。尚无外部用户数据，案例不代表对所有 Logo 的效果保证。
