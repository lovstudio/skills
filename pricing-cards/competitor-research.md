# 竞品调研 · v0.1.0

**0 Credits · 当前版本 Skill 包**

对点名的产品、公司或开源仓库做竞品调研，回答“区别是什么”“是不是基于某个项目二次开发”“含金量如何”“有没有投资价值”，每个结论都能回溯到证据。

- 包含四个调研模块（差异对比、血缘溯源、含金量、投资视角）、调研方法手册，以及只读取证脚本：GitHub 指标、提交历史、代码量与血缘检索。
- 在兼容的 AI 宿主中使用；需要网页检索能力，开源取证需要 git 与 Python 3.8+，GitHub 数据需要已登录的 gh。
- 热度比例只是参考，不能证明刷星；投资视角只做业务与技术尽调，不构成投资建议。
- 不含市场规模测算、付费数据库、需要登录的平台抓取、法律意见或人工代调研。

建议价、首发价与当前价格带均为 **0 Credits**。六维加权 2.9/5；证据来自一个真实的开源仓库案例：同一个取证脚本对已知无关的项目给出 0/308 个文件重叠，对目标起源提交点名的项目找出 19/709 个逐字节相同的文件和 2 个命中特有函数名的提交。目前只有一个案例，取证脚本还没有自动化测试，先以免费入口积累证据。

积累三个经用户验收的案例（其中至少一个是产品或公司对象）、十次真实使用，或为取证脚本补上自动化测试时复评。支持范围为当前可下载文件，无托管服务或更新时限承诺。

内部成本和价值估算单独记录，不作为产品展示价格或用户收益承诺。
