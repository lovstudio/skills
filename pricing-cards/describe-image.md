# Pricing Card — describe-image (lov-describe-image)

## 一句话结果与建议价

给纯文本模型（如 `deepseek-v4-flash`）补齐"看图"能力：把图片发给免费视觉模型 GLM-4V-Flash，返回文字描述，让 agent 能间接理解截图、图表、照片。**建议定价：免费（free_entry，0 CNY）**，作为生态免费工具上架，收集真实使用证据。

## 价格区间、计费形态、渠道与首发测试

- 计费形态：一次性安装，免费入口（`paid: false`）
- 渠道：官网 Skill Publisher（`lovstudio/skills` catalog）
- 价格区间：0 CNY（区间 [0, 0]）
- 首发测试：免费上架；若后续接入付费视觉后端（更强模型/更高配额）再评估 5–20 CNY 的付费增值层

## 成本底线与价值锚点

- **成本底线**：build 约 2–4h（单脚本 + Skill 包装 + 文档），维护约 0.5h/季，直接成本 ≈ 0（GLM-4V-Flash 免费档）。按创作者时薪假设折算 time_cost ≈ 300–600 CNY，但免费生态工具以获客为先，不回收成本。
- **价值锚点**：单次"看图"省去 1–5 分钟手动 OCR/转录/转述；对纯文本模型工作流是刚需补齐，替代方案是订阅视觉模型（月度数十元）或反复人工转录。`realization_rate` 取保守值（依赖使用频率）。

## 买家得到的结果、适用边界与使用风险

- **结果**：任意图片 → 结构化文字描述（物体/场景/布局/文字转录）。
- **边界**：需要图片磁盘路径；仅支持"图→文"，不做图片生成/编辑/转换。
- **风险**：免费档 GLM-4V-Flash 对**细节核对**（逐字转写）置信度有限，重要结论建议更强模型交叉验证；超 5MB 图片自动降采样可能损失细节。

## 推广策略、套餐关系与复评触发

- **推广**：配合 DeepSeek Harness 多模态话题的教程/blog 引流；作为"纯文本模型补视觉"的免费工具上架。
- **套餐**：暂无；未来可并入"Lovstudio 视觉套件"（image-gen + describe-image + document-illustrator）。
- **复评触发**：版本变化、连续 10 次真实使用、或接入付费视觉后端。

## 假设、证据缺口、来源与置信度

- **假设**：目标买家为 Claude Code + 纯文本模型用户；使用频率"偶尔但刚需"。
- **证据缺口**：无公开用户案例；免费档视觉模型在细节核对上的表现待更多实测。
- **置信度**：中。免费定位明确，价值证据（省时/替代支出）为保守估算。
- **来源**：skill 源码（`SKILL.md` / `scripts/describe_image.py`）、2026-08-20 本地真实 key 端到端实测、catalog 现有 `free_entry` 惯例。
