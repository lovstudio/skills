把已授权观察到的网站 API 证据转成可验证的 OpenAPI、API graph、JavaScript SDK、Swagger UI 或任务型 CLI。**建议价格：0 Credits**，先以免费验证入口积累更多目标适配器和真实使用证据。

## 价格区间、计费形态、渠道与首发测试

- 计费形态：一次性安装，免费入口（`paid: false`）
- 渠道：LovStudio 官网 Skill Publisher
- 稳定价格带：0 Credits
- 首发测试：0 Credits；累计 10 次真实使用或新增第二个生产目标适配器后复评

## 成本底线与价值锚点

- 成本证据：当前项目包含目标发现、契约、API graph、SDK、Swagger、CLI 和浏览器会话桥接，并由 17 项回归测试覆盖；目标站点变化会产生持续维护成本。
- 价值锚点：把接口梳理、契约编写、SDK 封装、Swagger 接线和 CLI 生成收敛为一次可回读流程。
- 价格位置：交付能力达到标准入口，但内置目标只有 ZenMux，且没有外部买家结果和重复使用证据，因此当前不收费。

## 买家得到什么

- 目标范围内的 manifest、OpenAPI 3.1、API graph 与 JavaScript SDK。
- 可选 Swagger UI、本地代理和任务型 CLI 包。
- 授权边界、凭据 containment 与输出回读规则。
- 当前内置支持 `zenmux.ai`；新站点需要先开发并验证适配器。

## 渠道与推广

官网用真实 ZenMux 案例解释从 discovery 证据到可调用工具的完整链路。后续积累多个生产适配器后，可评估适配器包、托管执行额度或专业落地服务；在那之前不承诺通用网站支持。

## 风险、假设与复评

- 风险：目标接口、前端 bundle 或鉴权策略变化可能使适配器失效。
- 假设：本地运行、用户自有授权会话、单目标适配器。
- 证据缺口：外部用户案例、重复使用率、支持工时和多目标适配成本。
- 复评触发：新增第二个生产目标适配器、累计 10 次真实使用、版本变化、托管执行上线或支持成本明显变化。
