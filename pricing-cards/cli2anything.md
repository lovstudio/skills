# Skill Pricing Card：lov-cli2anything

## 一句话结果与建议 Credits 价格

把已授权观察到的网站 API 证据转成可验证的 OpenAPI、API graph、JavaScript SDK、Swagger UI 或任务型 CLI。**建议价格：0 Credits**。内置目标已从 1 个增至 4 个，但仍没有外部用户的重复使用证据，继续以免费入口积累。

## 价格区间、计费形态、渠道与首发测试

- 计费形态：一次性安装，免费入口（`paid: false`）
- 渠道：LovStudio 官网 Skill Publisher
- 稳定价格带：0 Credits
- 首发测试：0 Credits；累计 10 次外部真实使用，或某个目标完成带凭据的在线验证后复评是否计入 VIP 会员

## 成本底线与价值锚点

- 成本证据：项目包含目标发现、契约、API graph、SDK、Swagger、CLI 和浏览器会话桥接；4 个目标适配器由 33 项回归测试覆盖，其中签名 SDK 已与官方示例逐字节核对。每个目标都会随对方接口、文档与鉴权变化产生持续维护成本。
- 价值锚点：把接口梳理、契约编写、SDK 封装（含签名与加密）、Swagger 接线和 CLI 生成收敛为一次可回读流程，每个操作都标注证据来源。
- 价格位置：交付能力达到标准入口；本次发版的免费模式是发布方约束，且外部买家结果仍缺，因此继续不收费。

## 买家得到什么

- 目标范围内的 manifest、OpenAPI 3.1、API graph 与 JavaScript SDK。
- 可选 Swagger UI（含本机签名代理）和任务型 CLI 包；写操作默认需要显式确认。
- 授权边界、凭据不落盘与输出回读规则。
- 当前内置目标：`zenmux.ai`、`dshfind.com`、自托管 Plane、`suanli.cn`；其他站点需要先开发并验证适配器。

## 渠道与推广

官网用 ZenMux 与 dshfind 的真实案例解释从发现证据到可调用工具的链路，用签名 SDK 说明对需要加签的开放平台同样适用。积累外部使用证据后，再评估计入 VIP 会员、适配器包或专业落地服务；在那之前不承诺通用网站支持。

## 风险、假设与复评

- 风险：目标接口、前端 bundle、公开文档或鉴权策略变化可能使适配器失效；只有文档证据的目标在首次带凭据调用前存在未知差异。
- 假设：本地运行、用户自有授权或公开文档证据、按目标逐个适配。
- 证据缺口：外部用户案例、重复使用率、支持工时、各目标带凭据的在线验证。
- 复评触发：累计 10 次外部真实使用、任一目标完成带凭据在线验证、托管执行上线、版本变化或支持成本明显变化。
