## 为什么免费

- 结果价值明确：输入模糊的对话线索，可返回经文件系统回读的现存文件、来源会话与存储层级。
- 当前证据仍在起步阶段：已有一个真实 P 头像找回案例、四项回归测试和真实 transcript 回读，但尚未覆盖文档、音频、视频与更多宿主。
- 交付是 MIT 公开源码，没有持续 API 或托管索引成本。官网先作为免费入口，降低采用摩擦并积累跨环境证据。
- 单次使用保守可省下约 10–45 分钟的任务翻找、全文搜索与路径核验时间；重复使用时价值更高。

## 用户得到什么

- 按对话主题、原话、文件类型或 session ID 搜索 Codex、Claude 等本地 transcript。
- 过滤 developer/system 噪声，提取用户、助手和工具调用中的本地路径。
- 关联同 session 的生成缓存与项目 `output` / `outputs` 目录。
- 实时验证存在性、大小和修改时间，默认不返回已删除路径。
- 不移动、复制、上传或发布命中文件。

## 风险、假设与复评

- 假设：用户有权读取目标 transcript 和本地文件；首发以 macOS、Codex 与 Claude 本地日志为主要环境。
- 证据缺口：更多文档/音视频案例、ChatGPT 宿主接口、跨平台性能和大规模 transcript 冷启动数据。
- 复评触发：版本变化、累计 10 次真实使用、支持成本明显变化，或加入托管索引、跨设备云搜索与付费连接器。
