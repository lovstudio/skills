一句话结论：作为免费基础能力发布。它把 thread ID 解析、唯一目标确认、应用内导航和 `navigated: true` 回读收束为一个动作，但核心执行仍由本地 Codex 宿主提供。

## 为什么免费

- 成本底线：预计已投入 2–4 小时创建、文档与验证，未来 6 个月维护约 1–2 小时；运行时没有模型、托管或 API 费用。本次以免费入口换取兼容性与复用证据，不从单次价格回收创作者时间。
- 价值锚点：一次使用预计节省 1–10 分钟的复制 ID、翻找侧边栏和误开相似任务成本，并降低“工具已调用但窗口未跳转”的假成功风险。
- 价格位置：结果范围窄、替代方式简单、公开源码易复制；单独收费会制造大于价值的采用摩擦。

## 用户得到什么

- 接受 thread UUID、Codex deeplink 或刚确认的唯一 session ID。
- 打开当前 Codex 主窗口中的准确任务。
- 只有宿主返回 `navigated: true` 才报告完成。
- 不取消归档、不发送消息、不创建新任务。

适用边界：不包含历史会话检索、跨设备同步、消息发送、分享、归档管理或托管支持。

## 风险、假设与复评

- 使用风险：相似候选未消歧、宿主工具不可用或 Codex 改变导航接口。
- 假设：主要运行在提供任务导航能力的 Codex desktop，导航无逐次服务成本。
- 证据缺口：10 次以上真实使用、多个 Codex 版本、安装与复用数据。
- 复评触发：累计 10 次真实使用、导航 API 变化、加入跨设备托管检索或支持成本明显上升。
