## 为什么免费

保持既有免费定位，降低分享真实案例的门槛。开发与维护存在成本，免费是目录贡献
策略，不代表零成本；内部成本与价值估算不作为公开售价或收益承诺。

## 六维评分

| 维度 | 分数 / 5 | 权重 | 依据与缺口 |
| --- | ---: | ---: | --- |

加权得分 3.15 / 5。继续作为免费目录基础能力，暂无单独收费计划。

## 用户得到什么

可导入官网的 JSON，或由 Agent 登录后提交的案例；包含真实 Input → Prompt →
Output、最终成品图、脱敏说明和发布前确认。普通投稿无需 GitHub 权限。
公开 Session 为可选；付费 Session 维护者路径单独授权。

## 边界与复评

- 目标需已收录且支持官网投稿；服务端决定写入是否成功。
- 准备、预检、发布和公开验收状态分别报告。
- 暂无量化节省时间、长期支持工时或用户采用率数据。
- 完成 10 次独立投稿、接口变化或支持成本显著增加时复评。
