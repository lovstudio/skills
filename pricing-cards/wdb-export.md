# 微信聊天导出 · Pricing Card

版本：0.1.4（目录 ID `wdb-export`、调用 ID `lov-wdb-export`）。包含在 Lovstudio.AI VIP 会员全套权益中，不单独定价、不兑换 Credits；会员价格以当前会员方案为准。源码私有，会员账号按版本下载完整文件。

把别人转发来的一张微信聊天记录卡片（可层层嵌套）导成一个可离线打开的网页：原文逐条保留、图片内嵌、链接可点、
带侧边目录，导出后自动与源数据核对。适合需要把一张很长的聊天记录卡片整理成文件、交给别的工具或别人看的人。

提供导出脚本（列出收藏里的聊天记录、导出、把已有文件与源数据重新核对）、数据格式与页面约定的说明，以及 28 项测试。
需要 macOS、本机微信 4.x、已完成密钥准备的万能微信秘钥（同在会员权益中），以及 Python 3.9+。使用前要在微信里
收藏这张卡片，并在聊天里点开一遍，这样正文和图片才读得到。

只处理聊天记录卡片，不导出整段会话；视频号只保留封面、作者、描述与时长，不含视频；分享卡片只有卡片保存的
标题和摘要；语音、视频、文件的内容和没点开过的图片导不出。头像、账号与群号不进入成品。
发布成分享链接这一步目前仅站点所有者可用，不在会员权益内。

一个真实案例：一张外层 7 项、共 535 条消息的嵌套卡片，约 15 秒导出，逐条回读一致，60 个本机图片文件全部对上。
案例不代表对所有卡片的效果保证。
