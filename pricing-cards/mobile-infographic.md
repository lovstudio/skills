# Pricing Card — Mobile Infographic

## 一句话结果与建议价

把已经形成的结论、证据与来源重排成 1080 宽竖屏、手机上真能读完的信息图卡，交付可编辑
HTML、2× PNG 与一份可复核的移动可读性审计报告。**建议定价：免费（free_entry，0 Credits）**。
默认产出**一张高度自适应的长卡**：标题先立观点，排位数据用条形长度编码，来源与工具收进页脚上方的附录。

## 成本底线与价值锚点

- **成本底线**：约 10–18 小时构建加 6 个月内 4–8 小时维护，按内部 250–450 元/小时折算为
  3500 / 7000 / 12000 元三档。渲染、审计与可读性测量全部在本地 Playwright 完成，
  没有托管与付费 API 成本。
- **价值锚点**：一次使用可保守减少 1–3 小时的字号试错、版式返工与导出检查，并把单位、口径、
  来源和可读性变成明确验收。
- **价格位置**：六维加权 3.3/5，属于标准交付；但公开源码易复制、外部使用证据还只有一组，
  因此先以 0 Credits 作为免费入口，与付费的「专业信息图」（139 Credits，16:9 咨询 Exhibit）
  形成互补：桌面重论证付费，手机重阅读免费。

## 买家得到什么

输入是一段已经形成的结论加可核查的来源；输出是可编辑 `card.html`、2× PNG、`brief.md`、
`source.md`、`audit.json`，系列另附 `manifest.json`。默认一张 `long` 自适应高度卡（宽度恒 1080、
上限三个 3:4 屏），需要固定比例时可切到 3:4、4:5、9:16、1:1。七个语义模板：结论卡、步骤卡、
关键数字、两项对比、通过与否决门禁、引文卡，以及按数值倒序的排位条形图；单卡页脚只留居中 Logo，
来源与工具写在分割线之后的附录里。

边界：覆盖排版、渲染、移动可读性审计与系列组织；不含内容写作、事实核查、生图插图、翻译、
托管渲染与平台发布。

## 渠道与推广

作为免费入口配合教程内容分发：给出「同一份结论在桌面 Exhibit 与手机卡片上的两种读法」的对照样例，
再用 `professional-infographic` 承接需要 16:9 论证图的付费需求。推广素材直接复用案例里的三张卡与
审计报告，让读者看到门禁拦住了什么（对比度 2.95:1、grid 撑宽 45px、大字号行高溢出）。

## 风险、假设与复评

- 使用风险：依赖本地 Playwright 与 Chromium；中文字体栈的度量差异会影响行高与溢出判定。
- 假设：用户提供已有结论与来源；在本地运行渲染；Skill 保持为模板与门禁层，不做托管渲染。
- 证据缺口：人眼复核未完成；缺少外部安装、复用与转化数据；可读性阈值尚未在其他品牌与语言上验证。
- 复评触发：100 次真实外部使用、五组公开案例、阈值或画布比例变化，或加入托管渲染、专有模板包、
  团队审阅与显著支持成本。
