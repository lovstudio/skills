## 为什么免费

- 成本底线：回溯估计排查存储结构、实现、测试和文档投入 4–8 小时，未来 6 个月维护约 2–6 小时，主要用于跟进桌面版存储结构变化；0.1.1 是上线次日的一次 zsh 兼容修复，改动仅限使用说明中的调用写法，仍在维护预估内。完全在本机运行，没有托管、推理或渠道成本。
- 价值锚点：一次迁移通常节省 1–3 小时的存储结构排查和手工复制；更重要的是让数百个旧会话在新账号里重新可见、可继续，并在 30 天自动清理前保住 Cowork 会话的对话记录。第二次真实迁移（2026-10-05）一次带回 133 个 Code 会话和 77 个 Cowork 会话。
- 价格位置：单次结果价值中等偏高，但每位用户通常只在换号时使用一到两次，复用沉淀弱；免费分发能降低首次尝试门槛，并换取跨机器、跨版本的验证数据。

## 用户得到什么

- 列出本机所有 Claude 桌面版账号的会话数量、时间范围、对话记录完好度和当前登录账号。
- 默认只预演；确认后把旧账号的 Code 会话与 Cowork 会话复制到当前账号，不覆盖已有文件、不改动旧账号目录和登录凭据。
- 识别只剩标题、对话记录已被清理的会话，默认跳过。
- 给迁移过来的 Cowork 会话写入较长的记录保留期，并提醒 Claude Code 的全局保留期设置。

适用边界：只处理本机桌面版会话；不包含 claude.ai 网页聊天、Projects、connector 授权、云端会话、定时任务，也无法恢复已被清理的对话记录。

## 风险、假设与复评

- 使用风险：桌面版存储结构未公开，版本更新后可能变化；全新目标账号首次迁移后，桌面版可能要重启一次才会载入迁移来的会话（2026-10-05 实测约 11 分钟未自动出现，重启后全部出现）；部分迁移后的 Cowork 会话仍把产出写到旧账号目录，旧目录需保留。
- 假设：用户在 macOS 上使用 Claude 桌面版；其他平台需要手动指定数据目录，尚未验证。
- 证据缺口：已有 2 次真实迁移，均为同一用户、同一台 macOS 机器；仍缺跨用户、跨机器、Windows 平台和桌面版新版本的迁移结果。
- 复评触发：累计 10 次真实迁移、桌面版存储结构变化、官方推出账号迁移功能，或支持成本明显变化。
