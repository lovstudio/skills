# write-professional-book（加密 Skill）

这是 Lovstudio 的付费 Skill。安装时只会下载加密分发包；登录并用 Credits 兑换后，运行时才会按账户权益解密。

```bash
npx lovstudio skills add write-professional-book
uvx lovstudio-skill-helper decrypt write-professional-book
```

解密输出仅用于当前 Agent 调用，不会把源代码写入安装目录。需要额外资料时，用 helper 按需解密对应相对路径。
