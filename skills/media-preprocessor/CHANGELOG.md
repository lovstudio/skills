# Changelog

## [0.2.0] - 2026-09-07

### Added

- 新增 `creator_handoff.py`，校验源身份、已完成渲染、文件哈希、源时间码与可选完整解码，输出 `media-preprocess-handoff/v1`。
- 附带可直接打开 MP4 的 Markdown 素材列表，明确完整增强与内容已审阅的状态差异，将句子精剪和包装交给 `lov-media-creator`。

## [0.1.1] - 2026-09-07

### Added

- 统一展示名为「视频素材精整」，保持调用 ID 与能力契约。

## 0.1.0 — 2026-09-06

- 新增原片只读的全片诊断、明亮自然视频增强与内容分段工作流。
- 提供源绑定、可恢复抽帧/本地 ASR、全覆盖取舍清单、视频渲染、源映射与实际解码验证。
- 删除须有内容、画面和边界证据，待复核默认保留；真实案例与工程合成测试分开记录。
- 声明共享 Profile、组合边界、维度地图、定价和本地分发状态。
- 支持完整 large-v3 本地 MLX 转录、保守 VAD 窗口及带来源的已完成块复用；合并跨块重复语句时保留真实重复发言。
- 增加 macOS Metal 连续调色后端；完整增强主片可复用分段，保留编码代际与原始音频来源。
- 素材库支持主题搜索、可用/待复核筛选与单一播放器；明确听审不可用时的证据与交付限制。
