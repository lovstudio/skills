# 更新发布验证

## 发布前

- 由最终已签名、已公证的包生成 feed/manifest；记录版本、架构、安装器、大小与摘要。
- 确认稳定版、预览版和各架构更新源没有互相引用。
- 测试单飞检查、超时、无更新、新版可用、下载失败、安装交接和重启后版本。
- 缺少签名更新产物、必需平台或公钥对应关系时阻止公开 release。

## 发布后

1. 回读公开 release，确认版本、架构和更新包齐全。
2. 直接请求 `latest.json`、appcast、完整包或 delta，记录状态、最终 URL、长度和摘要。
3. 对下载字节复查代码签名、公证、版本、架构与更新签名。
4. 从上一公开版本执行真实检查、下载、安装交接和重启。
5. 重新读取已安装应用版本，确认与 feed 目标版本一致。

CI 成功、tag 存在、上传完成或下载进度 100% 都不替代第五步。
