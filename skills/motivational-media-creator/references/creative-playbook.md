# 原创励志短片手册

以下是原创设计选择H，不是参考片的统计定律。已取样实看的事实及反例见
[Reference study](reference-study.md)，选型时先读，不能把本页建议倒写成频道观察。

## 1. 从处境到行动

受众不是抽象的“所有奋斗的人”。先选一种此刻处境：卡在开始、一次失败、长期无反馈，
再选一个核心选择。行动片可落到小动作；支持性片可落到被理解、休息或愿意求助，
纪念片可只保留回望。允许没有成功结局：提交一次、问一个人、休息后重新评估。
拒绝把结构性困境都归咎于不够努力，拒绝用“谁都能”抹去条件差异。

## 2. 开头必须兑现

三种候选承担不同任务：现场动作让观众看见问题；具体矛盾建立悬念；结果型先亮证明。
未经证实的数字不能做结果钩子。第一画面要与第一句发生关系；品牌短片缺省不以
无信息Logo动画占开头，这是品牌设计选择，不是原频道没有片头的事实。
安静命题、情景悬念、先给成就再否定完成，都是可选入口；不用固定三秒配方。
不要用无信息倒计时、虚构危机或羞辱式“你还在躺平”留人。

## 3. 结构选择而非模板填空

- 现场小行动：停住 → 缩小任务 → 完成一步 → 看反馈。
- 有证据的复盘：失败事实 → 当时判断 → 新证据 → 改法 → 局限。
- 长程坚持：重复与代价 → 一个变化 → 不确定但愿意继续。
- 人物叙事：只用已核实公开事实，有明确来源；不编内心独白。
- 支持性沉思：承认处境 → 给理解和空间 → 一个可选支持路径，不以冠军逆袭收尾。
- 主题蒙太奇：同一命题跨数个真实场景，允许二次低谷与回收，但不假造单人连续经历。

每段必须引入事实、选择或变化；重复“相信自己”没有叙事增量就删。

## 4. 声画编排

中文旁白先按自然口语试读，字数/时长只做估计；最终以真实录音时间线重排。
一句判断可以配一个动作加一个结果，而不是堆三个无关的励志大场景。
尝试先留一个完整动作再切、让动作接力、用环境声衔接空间；有语义理由才加速。
快切、黑场、手持、慢动作都必须有任务，不以频率高低代表高级。

情绪曲线可以是安静 → 摩擦 → 一个决定 → 动作更明确 → 平静落地，也可以多轮起伏。
高潮不是整段最响；也可以是音乐退开后的一次点击或一句普通的话。
先写静音观看时能看懂的动作链，再检查只听旁白时是否完整。

## 5. 声音简报

音乐需求写情绪阶段、乐器质感、留白、目标时长及许可范围，不指定照搬原曲。
旁白优先清晰，关键句可退音乐；不要用混响和压缩伪造演讲现场。
声音cue须对应时间/帧及来源：新录声音、自摄环境声、已许可音效/音乐。
音乐床连续构建一次，镜头切换不能重置乐句；有意撤掉或静置是设计，不必填满全片。
需要配乐却不可用则明确停在待配乐草稿。混音RMS变化不能证明某个乐器渐强或哪位讲者更激动。
所有响度/峰值目标由交付平台与实际测量决定，不把某个经验值写成官方标准。

## 6. 视觉、字幕与双画幅

视觉来自故事场所、光线和动作，不默认套品牌色。Logo使用批准素材且只作必要归属。
字幕保留完整语义，重点词少而准；不逐字跳色制造持续干扰。
9:16起点可用1080×1920、左右46/顶160/底260像素保守留白，但这不是平台官方规范，
必须按当前目标App真实界面检查。16:9单独构图，主体与手部动作都不能被裁掉。
封面只有一个主要承诺，缩小后仍可读；不加虚构成绩、伪造前后对比。

## 7. 片尾和实验

行动片片尾可回到片头对象，把计划变成一次可见动作；沉思或人物片可留在表情、
空间、纪念字幕或未解决的问题。先让情绪落稳，再做必要归属，不强求同一种闭环。
CTA可以没有；有则只提一个低门槛行动，不把观众的处境变成销售压力。
A/B每次只变一个开头或封面；预先约定观察窗与指标。没有实际测试不写提升百分比。
