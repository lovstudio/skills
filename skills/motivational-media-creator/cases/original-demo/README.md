# 原创生产包演示

## 输入与产出

真实用户输入：下载 TheMiro0r 频道主要视频，分析创作手法，为手工川制作励志视频 Skill。

本例最小 brief：面向卡在开始的独立创作者，以“先完成一个能跑的小版本”为题写 75–90 秒中文励志片。事实先于金句，语气是先行一步的同行者；不羞辱、不唯成功论、不过劳、不虚构手工川的第一人称经历。

产出是 84 秒、30fps、8 段分镜的原创制作计划，不是视频成片。270 个汉字的口播需真人实读确认时长，不用硬加速适配目标时长。

## 文件边界

- `script.md`：只有观众听到的完整口播，不含审批、研究、清权、下载状态或内部标签。
- `production.json`：结构化制作包，口播字段与内部设计、清权、QC、实验字段明确分开。
- `brief.md`：创作 brief、状态与证据边界。
- `check_validation.py`：无测试框架的正负例自运行检查。
- `validation-results.txt`：实际命令的原样 stdout、stderr 与退出码；临时负例由自检查脚本生成后清理。

## 证据与发布边界

本例最初写于公开下载0/8受限阶段，是独立原创演示，不是当时“已学习原片手法”的证据。
0.2.0已补齐8条原片、英文VTT与时间码取样研究，见参考研究；本例不倒写其创作来源，
不声称复现频道节奏、镜头或配乐。不引用或改写原频道台词，不复用素材，不模仿讲者声音。

自摄镜头与新录旁白均待执行；音乐未选定、未许可。片尾仅从运行时 Profile 的 brand.logo 读取已批准官方横向 Logo，等比显示；Logo 当前待提供、待核对许可，不复制进可分发 Skill。未提供时只保留内部文字计划draft，不能生成面向观众的无Logo品牌预览/成片，也不能靠删除引用进入ready/rendered-reviewed；不得用文字品牌名替代 Logo。draft 校验通过仅证明字段、时间线、引用和声明状态自洽，不证明实际权利归属或成片质量。ready 合成正例只是验证状态契约，不能作为真实渲染或清权证据。
