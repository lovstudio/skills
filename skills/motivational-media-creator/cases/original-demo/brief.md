# 原创演示 · 先完成一个能跑的小版本

- 用户输入：研究参考频道创作手法，制作手工川品牌专用励志视频 Skill。
- 本例最小 brief：为卡在开始的独立创作者写一支 75–90 秒中文励志片，主张完成一个可运行、可验收的小版本。温和具体，不羞辱、不保证成功、不过劳，不虚构手工川的第一人称经历。
- 输出：`production.json`，84 秒、30fps、8 个连续分镜，含 3 个开头候选、完整口播、声音意图、双版构图、权利账本、发布 QC 与尚未执行的 A/B 方案。
- 类型：原创演示脚本；不是成片、真实亲历或效果案例。没有引用、改写参考频道台词，也没有模仿其讲者声音。
- 证据边界：脚本与结构可静态验证；镜头、配音、音乐许可、响度、安全区与留存效果均尚未实证。
- 生产状态：draft。自摄/新录待执行，音乐未选定未许可；不得发布。
- 验证入口：在 Skill 根目录运行 `python3 scripts/validate_production.py cases/original-demo/production.json`。`validation-results.txt` 保留实际 stdout、stderr 与退出码，包括三项负例。
