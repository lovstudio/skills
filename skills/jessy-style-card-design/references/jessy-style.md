# Jessy 版式

来源：Jessy 的一张横版双面名片。原图属于第三方，不随 Skill 保存；这里只记录可以复用的版式规则。
Jessy 的机构标识、机构主色、建筑插画和文字都属于她的身份，
不是本版式的一部分。

## 1. 画布与分工

- 横版 90×54 mm，双面。渲染画布 1080×648 CSS px（12 px/mm），`scale: 3` 导出 3240×1944。
- 正面：暖白纸色底，回答“这个人是谁、怎么找到他”。
- 背面：主色整面铺底，只做品牌识别。

## 2. 正面骨架

坐标按 1080×648 画布，模板 [jessy-style.card.json](../assets/jessy-style.card.json) 用的就是这组值。

| 区块 | 位置 | 规则 |
| --- | --- | --- |
| 姓名 | 左上：left 120，top 98 | 主色、字重 600、54 px、字距 0.06em；英文名 30 px、ink3，与中文基线对齐，间距 22 |
| 中文职务 | left 120，top 186 | 25 px、ink2；多个身份用“ / ”分隔 |
| 英文职务 | left 120，top 230 | 19.5 px、ink3；与中文职务逐项对应 |
| 品牌标 | 右上：right 112，top 116，高 34 | 彩色横版 Logo，与姓名同处第一行区域 |
| 联络行 | 左列：left 120，top 318 | 主色实心圆角方块图标（32 px、圆角 4、白色图标 18 px、描边 1.9），文字 20 px ink2，行距 26；地址写成“城市 + 地址”前缀对，一城一行 |
| 二维码 | 右下：right 112，top 388，156 px | 白边 8；下方一行小字说明（13 px、ink3、字距 0.3em） |
| 地标线稿 | 右下角出血：right −6，bottom −2，宽约 600 | 暖灰墨线，透明度 0.3–0.4，在二维码之下 |

两条对齐线：左列（姓名、职务、联络行）共用 left 120，右列（品牌标、二维码）共用 right 112。
中间不放东西，留白把左列的信息和右列的识别分开。

## 3. 背面骨架

| 区块 | 位置 | 规则 |
| --- | --- | --- |
| Logo | 水平居中，垂直 43%，宽约 340 | 白色版；个人品牌或主品牌二选一 |
| 口号 | Logo 下方居中，top 约 384 | 衬线 21 px、白色 90% 不透明、字距 0.12em；中文里夹的英文单词单独收小字距 |
| 网址 | 底部居中，bottom 64 | 17 px、白色、字距 0.08em |

## 4. 色彩角色

| token | 用在哪里 | 取值 |
| --- | --- | --- |
| `accent` | 姓名、图标底块、背面铺底 | 主体 Logo 的主色；Jessy 原卡的机构色不沿用 |
| `paper` | 正面底 | 暖白，例如 `#FCFBF8` |
| `ink2` / `ink3` | 职务、联络行 / 英文名、英文职务、说明 | 两级暖灰，例如 `#4F4D48`、`#7B7870` |
| 线稿墨色 | 地标线稿 | 暖灰，例如 `#6C675E` |

主色只出现在三个地方。正面其余部分保持中性，主色的分量来自姓名和一列小方块，不要再加色条或色块。

## 5. 结构与身份的分界

| 保留（版式） | 替换（身份） |
| --- | --- |
| 两面分工、两条对齐线、中间留白 | 姓名、英文名、职务 |
| 主色出现的三个位置 | 主色色值（换成主体 Logo 的主色） |
| 字级层级、中英双行的排列 | 文字内容 |
| 方块图标样式、联络行排列 | 联系方式与账号 |
| 右下线稿的位置、大小、透明度 | 线稿内容（换成主体据点的地标） |
| 二维码的位置与尺寸 | 二维码本身 |
| 背面 Logo + 口号 + 网址的构成 | 背面 Logo、口号、网址 |

即使主体和 Jessy 同属一个机构，也不使用她名片上的机构 Logo 和建筑图；需要机构标识时，用主体自己拿到的官方文件。

## 6. 槽位

| 槽位 | 主体内容 | 来源 |
| --- | --- | --- |
| 姓名 + 英文名 | 主体的名字与英文名或拼音 | `user.name`、`user.latin_name` |
| 中文职务 | 1–2 个身份 | `user.title` 或用户确认 |
| 英文职务 | 中文职务的对应译名 | 用户确认；推断的标待确认 |
| 品牌标 | 彩色横版 Logo | `brand.logo` |
| 联络行 | 网址、公众号或邮箱、电话、地址中有来源的 2–4 项 | `brand.site`、`user.contacts` |
| 二维码 | 官方二维码 | `user.qr` |
| 地标线稿 | 主要据点的地标 | 已有名片、Profile 或用户确认的据点 |
| 背面 Logo | 白色版 Logo | 品牌目录 |
| 背面口号 | 主体已有的口号 | 已有物料或用户确认；没有就删 |
| 背面网址 | 主站域名 | `brand.site` |

来源只能是当前请求里用户说的、Profile、已有物料（旧名片、官网、品牌目录）。没有来源的槽位删掉，
版式靠留白吸收，不用占位文字填满。

## 7. 内容变化时怎么调

- 职务太长：先只留 1–2 个身份，再把字号降到 23 / 18；不折行。
- 没有英文职务：删英文职务行，联络行上移到 top 274。
- 联络行超过 4 行：`row_gap` 降到 20；超过 5 行就删次要的。
- 没有二维码：删二维码块，线稿保留，右列只剩品牌标。
- 没有线稿：删线稿块，其余不动。
- Logo 很宽或很高：高度控制在 28–40，右缘仍对齐 right 112。
- 背面没有口号：只留 Logo 和网址，Logo 移到垂直 50%。
- 二维码不要小于 140 px，低于这个尺寸在 1/3 缩放下容易解不出。

## 8. 常见陷阱

- 把 Jessy 的机构色原样搬过来：主色必须换成主体品牌色，否则像在冒用对方机构。
- 为了“像”而硬凑行数：原卡有几行联系方式，不代表主体也要几行。
- 线稿压住文字或二维码：线稿标 `decor`，透明度控制在 0.3–0.4，二维码底留白边。
- 背面口号挤着 Logo：两者之间至少留 Logo 高度的 0.4 倍。
- 字距过大把英文撑散：中文用较大字距时，英文单词单独包一层并收小字距。
