# User configuration

This public skill must not depend on a specific personal machine. Brand assets,
design guides, identity, and output paths use the following resolution order:

1. explicit CLI flags;
2. skill-specific environment variables;
3. shared LovStudio environment variables;
4. shared user profile;
5. packaged public LovStudio default;
6. ask once when the operation requires a value that still cannot be resolved.

## Shared profile

Default path:

```bash
${LOVSTUDIO_SKILLS_PROFILE:-$HOME/.lovstudio/skills/profile.json}
```

Relevant shape:

```json
{
  "workspace": {
    "output_dir": "$HOME/Documents/lov-skill-output"
  },
  "brand": {
    "name": "Your Brand",
    "profile": "$HOME/.lovstudio/skills/professional-infographic-brand.json",
    "design_guide": "$HOME/.lovstudio/skills/design-guide.md"
  }
}
```

## Environment variables

| Variable | Meaning |
|---|---|
| `LOVSTUDIO_SKILLS_PROFILE` | Shared profile JSON |
| `LOVSTUDIO_SKILLS_BRAND_PROFILE` | Shared brand-profile JSON |
| `LOVSTUDIO_SKILLS_DESIGN_GUIDE` | Optional brand/design guide |
| `LOVSTUDIO_SKILLS_OUTPUT_DIR` | Shared output directory |
| `LOVSTUDIO_PROFESSIONAL_INFOGRAPHIC_BRAND_PROFILE` | Skill-specific brand profile |
| `LOVSTUDIO_PROFESSIONAL_INFOGRAPHIC_OUTPUT_DIR` | Skill-specific output root |

CLI values take precedence over every variable.

## Initialize a brand

```bash
python3 "$SKILL_DIR/scripts/infographic_cli.py" init-brand \
  --name "Your Brand" \
  --logo "/absolute/path/to/logo.svg" \
  --site "https://example.com" \
  --primary "#1F2937" \
  --accent "#D97757" \
  --paper "#F7F4EF" \
  --copyright "Generated by Your Brand's Professional Infographic Skill"
```

Default output:

```text
~/.lovstudio/skills/professional-infographic-brand.json
```

The command refuses to overwrite an existing profile unless `--force` is
provided.

## Portability rules

- Expand `$HOME` and `~` only at runtime.
- Resolve a relative logo path from the brand-profile directory.
- Embed the resolved logo into generated HTML; do not leave a private local path.
- Never copy a private design guide into a public repository.
- Store LovStudio-specific defaults in one packaged profile, not throughout the
  workflow.
- Generated project metadata may record the resolved profile path locally, but
  published examples must use repository-relative or packaged paths.
