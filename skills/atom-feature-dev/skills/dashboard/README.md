# 功能控制台 · Feature Dashboard

![Version](https://img.shields.io/badge/version-0.2.2-CC785C)

读取真实 manifest、Profile 与运行证据的多形态控制面。根 Skill 已内置零依赖前端与
loopback-only Python bridge，可直接启动，不再只交付界面规范。

本模块是 lov-atom-feature-dev 自包含 Skill Kit 的一部分，通过根目录的
.atom-feature manifest 与其他模块交接。

## 验证

运行本模块校验器，或在根目录运行完整 Kit 校验：

    python3 scripts/validate_skill.py .
