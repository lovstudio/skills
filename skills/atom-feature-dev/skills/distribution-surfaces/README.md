# 功能多端分发 · Feature Distribution

![Version](https://img.shields.io/badge/version-0.1.1-CC785C)

从同一 SDK 构建 CLI、REST API 与 Agent Skill adapters。

本模块是 lov-atom-feature-dev 自包含 Skill Kit 的一部分，通过根目录的
.atom-feature manifest 与其他模块交接。

## 验证

运行本模块校验器，或在根目录运行完整 Kit 校验：

    python3 scripts/validate_skill.py .
