# Changelog

## 0.1.0 - 2026-09-25

- 初始版本：解密网易云 `.ncm` 为可播放音频，默认 MP3，`--format original` 保留
  FLAC 等原格式。
- 按封面帧长度跳过预留填充，修正 ncmdump-py 1.1.6 与 ncm2mp3 0.3.1 共有的
  音频错位问题。
- 解密后按文件头识别格式；写出后按磁盘上实际音频计算时长并与元数据比对（MP3 用
  字节数与码率，其他格式用 ffmpeg 解复用），下载中断的文件会失败；临时文件原子
  替换，失败不产出文件。
- 同名输出三分处理：无法播放则替换、有效则跳过、能播放但不符则标为 conflict；
  同批次两个输入写同一输出时不互相覆盖。按 4 MB 分块解密，峰值内存不随文件增长。
- 支持文件夹与递归、输出目录、dry-run、JSON 结果、日志、离线模式；默认跳过有效
  输出、替换损坏输出。
- 写入 ID3v2.3 或 FLAC 标签与封面；封面缺失时可从元数据地址下载。
- 回归测试 `tests/test_ncm2mp3.py`（13 个用例）。
