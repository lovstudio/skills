# Track-changes Rendering Brief

Use this checklist to prepare the image editor. It is a reusable brief, not a
prompt that should be copied without filling it from the actual image.

## Base image

- The supplied raster is the edit target and immutable base.
- Preserve its canvas, aspect ratio, crop, background, identity, source-language
  text, branding, counters, icons, borders, and structural spacing.
- Change only the specified translated text regions.

## Text changes

- List each exact old fragment and every location where it appears.
- Keep the old fragment legible in black or neutral gray.
- Apply one thin red strikethrough to the old fragment.
- Put the exact corrected fragment immediately after it in dark red.
- Keep unaffected translated text black.
- Do not add “勘误”, “Correction”, a legend, or a badge unless requested.

## Fit

- Preserve source-language and interface typography.
- Tighten or reduce only translated text, and only as much as needed.
- Do not expand the canvas or move unrelated interface elements without approval.

## Avoid

- No clean replacement that hides the old error.
- No redrawing faces, logos, names, badges, source text, metrics, or icons.
- No poster redesign, footer, side panel, watermark, emoji, or decoration.
- No paraphrased replacement text; render approved strings verbatim.

## Final inspection

Check semantics, visible rejection, independent corrected reading, layout
fidelity, repeated occurrences, and character-level accuracy before delivery.
