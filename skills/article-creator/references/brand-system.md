# 品牌系统

品牌事实来自共享 Profile；本文件只定义可移植的出版规则和 Warm Academic 安全默认值。

## 身份层级

- `publication`：公众号发布主体，决定文章署名与封面 Logo。
- `brand`：工作室或母品牌，决定官网、设计语言和品牌尾注。
- `products`：文章允许提及的产品，每个产品最多一个主链接。

三者不得相互猜测替代。发布主体缺少官方 Logo 时，应询问或暂停封面合成，不能用工作室或产品 Logo 顶上。

## Warm Academic

- 背景：暖米色、燕麦色、象牙白，避免纯白。
- 文字：炭灰或深石墨，避免纯黑。
- 核心点缀：陶土色；辅助色可选无花果紫、橄榄绿、仙人掌绿和灰蓝。
- 标题：经典衬线气质；正文：干净无衬线气质。
- 质感：纸张、印刷、哑光、克制留白；避免冷蓝渐变、霓虹、玻璃拟态和泛化科技感。

参考色只用于非 UI 视觉资产：

| 角色 | 参考色 |
| --- | --- |
| Canvas | `#F9F9F7` |
| Secondary canvas | `#F0EEE6` |
| Ink | `#181818` |
| Muted | `#87867F` |
| Terracotta | `#CC785C` |

## 文章品牌组件

- 品牌尾注只使用公开事实，不写 Profile 路径、版本、内部备注或生产 Prompt。
- 核心品牌文案跨文章保持稳定，不借当期主题临时发挥。
- 延伸阅读与品牌尾注分开：前者服务证据，后者说明发布者。
- 文章开头的 `4:3` 横向正文首图和消息列表分享封面使用同一发布主体官方白色横向 Logo lockup；母品牌 Logo 不得替代。

## Logo policy

- 只接受 Profile 或当前请求明确提供的发布主体官方白色横向 Logo lockup；方形图标、母品牌 Logo 和橙色变体都不是本公众号封面 Logo。
- Logo 作为后置确定性图层，不进入生图 Prompt。
- 保持原始比例、透明区域、颜色和字形；不得重绘、变形、描边或增加品牌面板。
- raster 合成默认使用透明 PNG；SVG 需先通过可信渲染器转成透明 PNG。
- 合成器按非透明内容框校验宽高比，默认必须大于或等于 `1.8`。
- 合成器按可见像素校验白色，默认白色像素比例必须大于或等于 `0.98`。
