# 公众号渠道写作补充

通用文风、个人语气和作者性不在本文件维护。新写与改写统一调用 `lov-writing-style`，并由它内置调用唯一反 AI / 作者性规则源 `lov-human-writing`。

本文件只保留公众号渠道约束：

- 默认读者不知道作者与 Agent 的对话、旧稿轮次和修改过程；标题与开头 300 字必须通过 zero-session cold-reader test。
- 移动端段落允许一句段与长段交替，但不得把全文机械切成同样长度。
- 研究评测类文章使用“测试方法”“Prompt”“评价指标”“评分方法”“评分示例”“复现方法”等朴素标题，且方法必须先于结果。
- 公众号品牌尾注、封面说明和延伸阅读是出版组件，不用于续写正文结论。
- 转载来源正文是冻结材料；只有发布方新增区块进入文风与作者性处理。

事实、当前请求和用户明确修改优先于任何风格 Profile。
