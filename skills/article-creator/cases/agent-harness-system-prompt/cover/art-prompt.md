# Art Prompt

Mode: built-in image generation

Use case: `stylized-concept`

Asset type: master editorial artwork for a WeChat long-form article cover.

Primary request: visualize the same language model gaining four different working personalities inside four different Agent Harnesses.

Scene and subject: a warm off-white editorial paper field; one central dark graphite model core held by four surrounding architectural frames, each built with a different construction logic. The result should read as one clear metaphor, not a technical diagram.

Style: premium editorial collage and printmaking, tactile cut paper, dry ink, restrained painterly texture, contemporary technology magazine art direction.

Composition: square master; strong centered focal area that survives a `2.35:1` center crop and a `3:4` portrait crop; low-detail horizontal center band for a later Logo; calm bottom 20 percent for a later portrait Logo; generous negative space.

Palette: warm paper, terracotta, charcoal, muted olive, gray blue and restrained lavender.

Constraints: no text, letters, numbers, typography, Logo, watermark, UI, code screens, robots, human faces or fake writing. Avoid neon cyberpunk, glowing particles, circuit-board clichés, stock office photography, floating app icons and excessive complexity.
