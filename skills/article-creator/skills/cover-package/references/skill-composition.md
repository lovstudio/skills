# Skill composition

## Nearby Skills Inspected

`lov-wechat-branding-cover-composition` 提供横版品牌合成规则；通用 imagegen 提供无字艺术底图。

## Atomic Handoffs

本模块接收文章命题、底图和官方 Logo，输出分享封面、`4:3` 正文首图及 cover manifest 给质量门。

## Overlap Decisions

保留艺术层与品牌层分离；正文首图按公众号出版规范使用独立的 `4:3` 横向构图。

## Composition Decision

确定性裁切、Logo 合成和 manifest 随 Kit 分发；图像模型不是 Logo 或最终尺寸的 owner。
