# 演示引擎契约（Demo Guide）

由 `assets/template.html` + `scripts/build_viz.py` 产出的自包含 HTML，
是一个统一播放引擎。所有可视化共用同一套控制与设计，保证“逐步、方便演示”。

## 播放控制

| 控件 | 行为 |
| --- | --- |
| 回到起点 | 跳到第 1 帧 |
| ← 上一步 | 后退一帧（停止播放） |
| 播放 / 暂停 | 按速度自动推进；到末帧自动停 |
| → 下一步 | 前进一帧（停止播放） |
| 速度 | 慢 / 中 / 快（默认中 ≈ 720ms/帧） |
| 进度条 | 显示当前帧占比，点击跳转 |

## 键盘快捷键

- `Space` — 播放 / 暂停
- `←` / `→` — 上一帧 / 下一帧
- `R` — 回到起点
- `1` / `2` / `3` — 慢 / 中 / 快

按键监听挂在 `window` 上，但若焦点在按钮/下拉框等可交互元素上则不拦截
（避免打断操作）。演示时建议全程用键盘，双手不离键盘最流畅。

## 每帧同时展示的信息

- **舞台**：节点/边/柱子的高亮（active 高亮、settled 变实、rejected 虚化）
- **解说条**：`STEP n / m` + 当前帧 `note` 的一句话中文解说
- **伪代码面板**：高亮当前 `codeLine`
- **指标**：`metricLabel` 的已完成计数 + 当前帧号
- **关键直觉**：顶部 `insight` 卡，一句话点破原理

## 设计规范（Lovstudio 暖学术）

- 配色：暖米背景 `#F9F9F7`、炭灰文字 `#181818`、陶土主色 `#CC785C`
  （次选鼠尾草 `#6E8B7B`、琥珀 `#E6A94A`）
- 字体：正文系统中文栈（PingFang / 雅黑），数值用等宽栈（SF Mono / Menlo）
- 图标：内联 SVG，**禁用 emoji**（含 → ↑ ✓ ✗ × 等特殊符号）
- 风格：克制、留白、圆角小、无阴影堆叠

产物不引用任何外部 CDN 或字体文件，离线可用；双击 `file://` 即可演示。

## 手动扩展（引擎未覆盖的布局）

若算法需要非本引擎的视觉（例如网格寻路 BFS/DFS、树形力导向），有两种做法：

1. 优先尝试用现有布局近似：网格寻路可用 `matrix`（每格一个节点 + active/settled），
   树可用 `network`。
2. 确需自定义时：手写 HTML，但**复用本文的控制与设计契约**（同样的播放/暂停/
   逐帧/速度/键盘/解说条/伪代码高亮），不要另造一套交互，否则“方便演示”会打折扣。
