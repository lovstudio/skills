# 视频号上传约束

## 执行优先级

按以下优先级判断：

1. 当前账号创建页展示的限制、校验错误与功能开关；
2. 本文记录的官方前端基线；
3. `scripts/check_video.py` 的保守默认值。

平台会按账号、灰度开关和发布时间调整限制。每次执行都先读实时页面；页面文案与本文不同时，记录原文并以页面为准。脚本覆盖参数只调整文件大小和最长时长，不代表账号已获得对应能力。

## 保守硬限制

脚本默认执行下列阻断校验：

| 项目 | 默认值 |
| --- | --- |
| 文件大小 | 不超过 4 GiB（`4 × 1024³` 字节） |
| 视频时长 | 3 秒至 2 小时 |
| 宽高比 | 1:3 至 3:1（含边界） |

缺失视频流、时长或有效宽高时也阻断，因为素材尚未满足可验证的硬限制。脚本只调用 `ffprobe` 读取元数据和文件大小，媒体文件保持原样。

## 建议项

以下项目产生警告，不单独阻断上传：

- MP4 容器与 H.264 视频编码；
- 分辨率 720p 及以上，脚本以短边至少 720 像素检查；
- 视频码率不超过 10 Mbps；
- 帧率不超过 60 fps；
- 存在音轨时使用 AAC、码率至少 128 kbps、采样率至少 48 kHz。

警告表示偏离平台建议，不代表上传必然失败。最终仍需观察当前页面的素材解析结果。

## 20 GiB / 8 小时灰度

2026-08-11 回读的视频号助手官方前端包含 `enablePost20gVideo` 功能开关：关闭时页面使用 4 GiB / 2 小时，开启时使用 20 GiB / 8 小时；最短时长仍为 3 秒，宽高比仍为 1:3 至 3:1。只有当前账号页面明确显示放宽文案时，才运行：

```bash
python3 <本 Skill 目录>/scripts/check_video.py <视频路径> \
  --max-gb 20 --max-hours 8 --json
```

若实时页面显示其他值，使用页面值重跑相应覆盖参数，并把页面原文、账号和时间留在执行证据中。
