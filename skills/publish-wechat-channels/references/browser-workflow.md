# 视频号助手浏览器工作流

## 操作原则

- 只使用可见浏览器页面，入口为 `https://channels.weixin.qq.com/platform/post/create`。
- 每次点击、输入或上传前重新获取当前页面快照。优先按可访问角色、可见名称、字段标签和邻近说明定位。
- 不跨页面复用元素句柄、CSS 选择器、DOM 序号或屏幕坐标。页面更新、弹窗出现、上传阶段变化后重新定位。
- 同名按钮有多个时，结合所在表单、标题和附近字段缩小范围；仍不唯一时不要点击。
- 复用用户允许控制的前台实例。登录二维码、账号选择或安全校验出现时让用户接手，完成后再重新读取页面。

## 页面阶段

1. **登录与账号**
   - 登录页通常显示二维码；等待用户扫码、在手机端确认并选择账号。
   - 登录后读取导航区或账号菜单里可见的视频号名称。与预期账号逐字核对，不以头像颜色或浏览器历史推断账号。

2. **上传**
   - 从带有“上传视频”“选择文件”或同义可见文案的区域，定位其关联文件选择控件。
   - 选入绝对路径后，重新读取文件名和进度。实际进度出现才进入 `uploading`。
   - 100% 只表示传输完成。平台仍显示“处理中”“转码中”“解析中”、骨架屏或封面生成时进入 `processing` 并继续等待。
   - 页面显示可播放预览、时长/封面且没有错误提示后，再编辑发布信息。

3. **发布信息**
   - 按标签定位描述/文案、话题、封面、位置、合集等字段；输入后失焦并逐项回读。
   - 用户给出封面图时走当前“上传封面”语义入口；给出时间点时走“从视频选择”入口并核对画面。其余情况保留平台默认封面。
   - 只设置用户明确要求的可选项。当前会话已确认的主题、标题、描述和话题必须保留在表单中并完成回读；出现空值就停在提交前。
   - 用户明确要求原创时，勾选“声明原创”，完成“我已阅读并同意”及平台条款确认，再回读原创复选框已选状态；未明确要求时保持默认。
   - 描述编辑器可能是 contenteditable、子 frame 或 shadow DOM；点击后使用当前焦点输入并重新读取实际文本，不把占位词“添加描述”当成已填写内容。

4. **提交分支**
   - 草稿：定位当前创建表单里的“保存草稿”或同义次要动作，确认后打开内容管理的草稿列表。
   - 定时：定位“定时发布”设置，读取页面使用的时区，填写并回读完整年月日时分，再提交。
   - 发布：定位创建表单的“发布/发表”主动作；在确认弹窗中复核账号、内容类型和时间后只提交一次。
   - 状态查询：不进入上传与编辑；打开内容管理列表，重载后用条目链接、ID 或组合指纹定位目标，并记录平台状态原文。

## 回读与防重

提交后进入对应内容管理列表，执行一次真实重载，再以组合指纹查找：

- 当前视频号账号；
- 文件名或页面生成的标题；
- 文案前缀；
- 封面缩略图；
- 本次操作时间窗口；
- 定时时间（如有）。

只有唯一匹配条目可作为证据。草稿需读到草稿条目，定时需读到正确时间与定时状态，公开发布需读到“已发布/已发表”等明确状态；“原创审核中”“审核中”“转码中”等原文属于 `platform_pending`，不等同于 `published`。查询若读到失败或拒绝，也按状态契约映射并保留原文。记录条目链接或 ID、状态原文、列表 URL、账号和回读时间。

若提交响应中断、页面卡住或确认结果未知，先重载内容列表查找指纹。找不到时保留最后已确认状态并报告，不要再次点击发布。若出现多个匹配条目，报告全部候选并停止后续动作。

## 错误证据

收集当前页面可复制的完整错误原文，并连同以下调试信息回报：步骤、最后状态、账号、文件名、文件大小/时长、当前 URL、发生时间、上传百分比或处理文案、列表回读结果。源视频始终保持只读。

### 动态上传控件

上传区可能由子 frame 或 shadow DOM 渲染。标准 CSS 选择器找不到文件输入时，重新读取当前 frame tree 和可穿透的 DOM，以当前可见上传区域为邻近依据定位文件控件；使用文件设置能力提交绝对路径，并重新读取实际进度。每次页面更新都重新取得节点信息，不复用旧 node ID、句柄或坐标。
