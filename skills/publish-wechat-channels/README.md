# 微信视频号发布

![Version](https://img.shields.io/badge/version-0.0.2-CC785C)

通过已登录的视频号助手网页预检、上传并发布视频，支持保存草稿、定时发布和发布状态回读。

## 适用场景

- 发布微信视频号视频
- 保存视频号草稿或安排定时发布
- 回读视频号内容列表中的审核、转码或发布状态
- 按用户已确认的短标题、描述、话题、封面和原创声明完成逐项核验

## 使用前提

- 浏览器中已登录目标视频号助手账号，并能打开 `https://channels.weixin.qq.com`。
- 发布或保存草稿时准备本地视频绝对路径。
- 媒体预检只读调用 `ffprobe`，不转码、不覆盖源视频。

## 安装

```bash
npx skills add lovstudio/oneshot -g -y
```

## 关键行为

技能会在写入前回读用户已确认的标题、描述、话题和原创状态；提交后重新加载内容管理列表。列表显示“原创审核中”等处理中状态时，会保留平台原文并报告为 `platform_pending`，只有列表明确显示“已发布/已发表”才报告 `published`。
