# Changelog

## 0.1.0 — 2026-11-21

- 首版：随附 lov-cli2anything（suanli.cn 适配器）从共绩算力公开文档生成的 `lov-suanli-cli` 0.1.0、SDK、OpenAPI 3.1 与本地 Swagger 代理。

- `scripts/gjkj_cli.py`：
  - `ops`：列出命令并标注读写、计费、加密和实测状态；
  - `doctor`：自检运行环境，凭据只报长度；
  - `run`：调用命令，写操作和计费调用必须带上用户原话的同意，否则直接拒绝；
  - `swagger`：启动本地 Swagger 代理。
- 参考资料：常用命令、认证与密钥、返回码与常见错误、重新生成流程。
