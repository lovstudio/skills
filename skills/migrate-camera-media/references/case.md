# 2026-09-06：FX3A → T7 Shield

这是匿名化的操作案例，不包含可复用删除授权、固定卷 UUID 或默认目的地。

| 观测 | 处置与可复用经验 |
|---|---|
| 初始相机连接仅 12 Mb/s，实测约 1.1 MB/s；目标 SSD 10 Gb/s | 先诊断链路并安全停止；跨盘移动无法绕过瓶颈。 |
| 更换线缆后相机 5 Gb/s、SSD 10 Gb/s | 实际复制约 301 MB/s；不要用线缆的雷电标称速率替代协商结果。 |
| 初始 63 文件、108.77 GB；重新连接后 51 文件、92.39 GB | 对比快照，发现 6 个 MP4 和 6 个 XML 共 16.38 GB 不再在卡上；保留旧会话，用新快照备份现存内容。 |
| 用户随后确认另行转移并给出本机目录 | 12 个文件大小与旧清单一致，6 个视频首中尾抽查通过；无旧源哈希，不宣称逐字节相等。 |
| 2 个 RSV 共 19.06 GB | 原样复制并校验；复制成功不代表录像已修复。 |
| macOS 生成 69 个 AppleDouble 旁文件 | 校验文件头并单列；素材抽查只选择源清单，不用 glob 把旁文件当视频。 |
| 92.39 GB 复制 306.65 秒，复制与校验合计 489.59 秒 | 有界流水线顺序读卡、写盘、哈希；之后独立打开目标回读约 505 MB/s。 |
| 用户最终明确接受备份安排并选择电脑端清卡 | 复核身份与已验证副本后删除；遇到 uchg 保护不解除。保留 0 字节 SONYCARD.IND，回读约 239.99 GB 可用空间。 |

另一个改进点是及早预检 Python 依赖、diskutil 字段和原生文件属性接口，避免在真实媒体上反复启动失败。工具测试应完全使用临时目录与模拟身份。
