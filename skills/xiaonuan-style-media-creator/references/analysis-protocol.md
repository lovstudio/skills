# 参考视频分析协议

## 冻结样本

源文件只读。先记录 URL、SHA-256、时长、画幅、编码与音轨，再冻结训练与留出拆分，最后才做规则选择。v0.1 的样本取自博主主页当前格式期（2026-09-18 至 2026-11-06），按互动量和子类型（连麦个案、观点题、置顶服务介绍）分层挑 12 条，主页第 23、40 条为留出。规则支持度的分母是适用的训练样本，不含留出。

小红书未登录时笔记 ID 为空，需在已登录的浏览器里读取 ID 与 xsecToken；笔记详情里带音轨的 mp4 直链交给下载能力，下载报告与哈希一起保存。

## 时间证据

完整转写保留原始 JSON 与词级时间。v0.1 用本机 Whisper large-v3（通义听悟离线脚本当时不可用），专名有误听，证据按原样引用，不改写原话。引文必须是保留下来的源段的精确子串，由构建脚本核对。

全片测量用 FFmpeg：场景检测 320 px、阈值 0.23（会漏掉轻微跳切）；silencedetect -35 dB / 0.2 s（混轨静音，不是人声 VAD）；loudnorm 测整片响度与 True Peak。`separator_scan.py` 以 0.25 秒窗口找 1 kHz 测试音，发现分隔与拼接点，再用画面确认是否为彩条。

## 画面与版式

每 2 秒抽一帧做 macOS Vision OCR（`scan_layout.py`）：顶部区域判断标题行、字高与持续时间；中下区域统计字幕覆盖率、每行字数、字框高度与位置、是否带标点；左上多行判断资料卡。坐标为左上角归一化，不跨画幅硬套。颜色从文字框像素聚类取 hex 值。精确字体、剪辑软件与工程参数无法核实，保留为未知。

## 说话人

不做分轨。连麦来访者与主播常走不同的音频通路，`speaker_hint.py` 用 4–7.5 kHz 与 0.3–4 kHz 的能量比做二聚类，只作提示；角色以通读全文的语义判断为准。主播与来访者的说话占比不作为规则依据。

## 规则

每条规则写观察、生成指令、适用条件、证据 ID、支持样本、分子分母、例外、置信与验收方式。反复出现的是共性，只在部分作品出现的是变体或可选项。题材、人名、资质、服务承诺和未证实的市场或性别判断不是可迁移风格。不得用模型补齐不存在的原片例句或伪造支持数量。

## 留出验证

先冻结画像并记录 SHA-256，再读取留出的全文与抽帧，用固定规则逐条记录命中、部分、未中与不适用。批量测量日志若提前显示了留出数值，在报告中标为已污染，不算独立验证。基于留出或冻结后才统计的训练集发现，只写入下一版修订候选，不回改冻结版。

## 外部服务

只发送公开或已授权素材。凭据从进程环境或系统凭据存储读取，禁止写入源包、Profile、URL、日志或案例。原片、截图与完整转写只留在本地分析目录，不进入安装包。
