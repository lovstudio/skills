# lov-illustrate

![Version](https://img.shields.io/badge/version-2.6.2-CC785C)

> 为md文档智能添加插图，提升可读性

为 Markdown 长文规划、检索、生成和组装可溯源插图，覆盖真实素材、数据图表、
程序化合成图和生成式 AI 概念图。包含 CJK 语言分段、字体覆盖和浏览器实际
fallback 回读门禁，避免缺字或混用字体被固化进 PNG/JPG。

## Installation

```bash
npx skills add lov-illustrate -g -y
```

## Invocation

```
使用 lov-illustrate 完成以下任务：<任务目标、输入和约束>
```
