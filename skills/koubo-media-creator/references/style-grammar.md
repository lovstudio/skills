# 风格语法：AI 工具口播短片

「对」的标准。规则从一位 AI 工具口播博主的公开作品里量出来（2026-10-28 采样：B 站近 30 条元数据与封面、
7 条代表作的逐句转写与 1.5 秒接触表，样本 BV 号见文末），抽象成**片型语法**，不复制任何个人特征。

## 0. 边界：复刻片型，不复刻人

- 出镜人、声音、账号名、水印、片尾关注卡、封面人像，一律是**作者本人**（Profile 里的 `user` / `brand`）。
- 不用样本博主的口头禅原句（例如以「我的天啊」开头的固定结尾句）、昵称、固定开场白；`check_script.py` 有禁用表。
- 不搬运样本里的素材、截图、封面图。上屏证据只来自作者自己的操作、公开官网/文档截图（标注来源）或本片生成图。
- 片型（结构、节奏、版式、字幕与封面语法）是行业通用手法，可以学；「看起来就是那个人」的东西不学。

## 1. 量出来的硬指标

| 指标 | 样本观测 | 本 Skill 默认 |
| --- | --- | --- |
| 画幅 | 竖版 2160×3840 为主（少数 4:3 / 3:4 机位） | 1080×1920，30 fps |
| 时长 | 32 s（清单）～ 230 s（锐评榜），主体 70–130 s | 按片型，见 §2 |
| 语速 | 4.9–7.3 字/秒，中位约 6.0 | 估时用 5.8 字/秒；>7 字/秒的段落要求拆句 |
| 上半屏换画面 | 平均 1.9–3.6 秒一次；清单片 0.9 秒一次 | 单个上屏素材 ≤ 4 秒，超了拆成两张或加推近 |
| 整画面硬切 | 平均 3.7–8 秒一次 | 布局（分屏/全脸/全素材）每 2–4 句变一次 |
| 句间静音 | 几乎没有；p5 底噪约 −41～−44 dB（有轻音乐床） | 句间气口 ≤ 0.25 秒，配乐 −28～−32 dB 垫底 |
| 结尾 | 「你学会了吗」类一问 + 1–3 秒关注卡 | 一句提问或行动号召 + 2.5 秒作者关注卡 |

## 2. 片型五式（选一个，写进 `script.json.format`）

每一式都是「**结果先行 → 痛点/悬念 → N 个点（每点一证据）→ 判断 → 一问收尾**」的变体。

| format | 标题公式 | 时长 | 结构 |
| --- | --- | --- | --- |
| `list` 清单速览 | 「N 个 X，30 秒看懂！」 | 25–45 s | 每条一句「这个 X 可以 Y」+ 前后对比图，0.8–1.5 秒一张，最后一问 |
| `tips` N 招技巧 | 「花了 X 积分/天，总结了 N 招」「X 一定要开的 N 个设置」 | 35–100 s | 前后对比钩子 → 「但要用到极致你还得会这几招」→ 每招：痛点一句 + 操作一句 + 结果一句 |
| `review` 首发实测 | 「X 首发实测，N 个工作流都接住了！」 | 90–130 s | 「这是新出的 X。这是我给它安排的 N 道测试。」→ 每测：任务 → 过程截图 → 结果 → 一句评价 → 总评「它更像一个……的同事」 |
| `tier` 锐评榜 | 「从夯到拉锐评 X 的 N 个功能！」 | 150–240 s | 开场定义档位（夯/顶级/人上人/NPC/拉完了）→ 每项：「第 N 个，A，这一波给到 B」+ 理由 2–3 句 + 证据 → 档位表常驻角落 |
| `case` 案例故事 | 「靠 AI 一个人管 5 家店」「X 都开始用 Agent 偷懒了」 | 90–140 s | 反常识场景提问（「如果你收到……你的第一反应是什么」）→ 主角怎么做到 → 工具复现 → 数据/规模 → 你可以怎么用 |

## 3. 口播语法

- **第一句就是结果或反差**，不寒暄、不自我介绍：「在 X 上点开设置栏，选终端，输入 Y。恭喜你！」
  「这是之前的 AI 哭戏，而这是现在的。」钩子 ≤ 3.5 秒（≤ 20 字），画面必须同时给出证据。
- **第二拍立悬念或痛点**：「那怎么分工呢？」「但肯定很多人都很烦恼……」「但要把它用到极致，你还得会这几招。」
- **实验者身份**：用作者真实投入建立可信度（「烧了多少积分」「测了几天」「给它安排了 N 道测试」）。
  只写作者真实做过的；没有投入数据就不写，不编。
- **操作句具体到按钮**：「点开 A，选 B，输入 C」。抽象功能一律落到「你看，……」+ 屏幕证据。
- **短句**：一句 8–22 字为主，口语连接词「那」「然后」「还有一个就是」「你看」，允许「就完事了」「真的可以玩」这类口头判断。
- **每个点都有评价**：「这一波必须给到 X」「整体使用感相当好」「还需要人来干涉」；正反都说，承认短板（可信度来源）。
- **收尾一问**：「你学会了吗？」或一句行动号召，紧接关注卡。不用样本博主的固定收尾句。
- 禁用 AI 腔：在当今时代、赋能、让我们一起、总而言之、不仅……更……、值得一提的是、深度解析、颠覆、炸裂（除非引述）。

## 4. 画面语法

三种布局，按句子切换（`lines[].layout`）：

| layout | 画面 | 用在 |
| --- | --- | --- |
| `split` 默认 | 上 ~52% 上屏素材（截图/录屏/对比图，黑底），下半作者实景出镜，字幕压在交界 | 讲操作、讲证据，占全片 60–75% |
| `face` | 作者全屏出镜，胸口位置放橙色大标注（《功能名》） | 钩子后的悬念句、判断句、收尾一问 |
| `broll` | 素材全屏（黑底留边），作者不出镜，字幕在下 1/3 | 前后对比、「修改前/修改后」、需要看清细节的截图 |

- 上屏素材自带**红框**圈重点（`boxes`），在句首 0.2 秒弹出；截图默认慢推近 1.00→1.06，`focus` 指定推向区域。
- 「修改前 / 修改后」「第 N 招」这类橙色标签贴在素材左上（`label`）。
- 章节式大标注（`callout`）：橙黄渐变粗体、黑描边、硬投影、轻微倾斜，弹入 4 帧。
- 镜头之间硬切，新素材 0.96→1.00 轻弹入；不做花哨转场。
- 作者实景背景保留（书架、灯、绿植），不抠像；出镜机位胸口以上，脸在下半区中上部。

## 5. 字幕语法

- 每条 ≤ 14 字，按语义断（jieba + 标点），白色特粗黑体（Noto Sans SC 900），10 px 黑描边。
- 关键词（产品名、数字、结论词，`emphasis`）同句里换成黄橙色 `#FFC21A`、字号放大 1.15×。
- 字幕时间来自最终录音的逐字对齐，文字以脚本为准（ASR 只给时间，不给字）。
- 竖版安全区：顶部 160 px、底部 260 px 不放字幕与标注。

## 6. 声音

- 人声是唯一主角：高通 70 Hz、轻压缩，整片 −16 LUFS-I、≤ −1.5 dBTP。
- 一条按内容生成的轻快电子/Lo-fi 音乐床，人声下 −28～−32 dB 持续不停，最后挂载、只挂一次。
- 不配解说式音效轰炸；可选：素材弹入轻「嗒」、红框轻「叮」（需要时再加）。

## 7. 封面语法（3:4 视频号、16:9 B 站同一套视觉）

- 底：近黑到深棕，中心或人物后方橙色光晕；可叠本片关键截图（倾斜卡片、橙色描边、圆角）。
- 主标题 2–3 行、每行 ≤ 7 字，最大字占画宽 70% 以上；黄 `#FFD60A` 与白交替，14 px 黑描边 + 硬投影，轻微倾斜或异字号。
- 作者抠像：夸张表情（张嘴惊讶 / 指向标题 / 竖大拇指），占画面 35–50%，不压标题。录制时先拍 3 秒封面表情（提词器第一页提醒）。
- 小标签：黄底黑字圆角块（「3 招超实用」「附提示词」），一张封面最多一个。
- 缩略图验收：3:4 在 270×360、16:9 在 480×270 下一眼读完主标题。

## 8. 片尾关注卡（2.5 秒）

作者头像圆框 + 名字 + 一句「关注我，带你玩转 AI」（从 Profile `brand.tone` 改写）+ 可选：作者往期封面网格。
不用样本博主的头像、名字、关注页。
