# Skill Group Composition

## Nearby Skills Inspected

- lov-frontend-design：界面、控件和实际交互验证；不管理单项工具注册与计费映射。
- lov-api-creator：独立 API 的前后端合同；仅当任务需要新服务时交接。
- lov-better-seo：公开路径与索引审查；消费已实现的路由。
- lov-release-via-cicd：消费已通过检查的提交，按用户部署授权发布。
- lov-branding-consistency：审校目标产品的用户可见文案。

## Atomic Handoffs

本 Skill 接收工具用途、输入输出与项目代码，交付组件、目录注册、语言键、站点地图和验证证据。新增 API、品牌审校或部署只交接对应明确制品。

## Overlap Decisions

保留项目旧 /add-tool 的工具集成结果；UI 设计和 API 开发可复用相邻能力，不复制完整方法。工具创建不包括未经授权的广播通知。

## Composition Decision

Single Skill：工具实现、注册、多语言与成本显示共享同一项目合同，分拆会导致路径与状态不一致。
