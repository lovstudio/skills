# Changelog

## [0.3.0] - 2026-09-07

### Added

- 新增按源色彩证据执行的摄影调色，支持 S-Log3 / S-Gamut3.Cine 与 Rec.709 还原。
- 声明长期修图方法偏好，用户已选择摄影调色时直接沿用，保持明亮自然视觉方向。
- 补齐流元数据与 Sony XML 读取、16-bit 原片解码、曝光和白平衡校准，以及 sRGB JPEG 导出。
- 明确未知色彩拒绝普通增亮、多源逐源验收、文件/像素双哈希及 ICC 元数据差异处理。
- 增加六张摄影调色的脱敏真实案例与六项色彩/来源回归测试；不把方法选择记为逐图审美批准。

## [0.2.0] - 2026-09-06

### Added

- 固化用户认可的明亮自然美化基准
- 区分视觉批准与纪实保真，保留批准结果并仅修指定问题
- 修正触发描述、版本徽章和验证 CLI 参数入口

## 0.1.1 — 2026-09-06

- 增加投影教室的主体曝光检查与偏暗反馈修图 brief，按人物局部和手机缩略图验收提亮效果。
- 真实案例新增六张统一尺寸的明亮 AI 美化图、原图对比和下载包；如实保留课件小字重绘的失败记录，未放宽纪实打包门禁。

## 0.1.0 — 2026-09-06

- 从视频制作朋友圈纪实组图，区分可观察画面与需核对对白的知识 moments。
- 新增长视频稀疏索引、局部细筛、源帧提取、中断续跑及已验收照片打包。
- 保留时间码、源帧与成图哈希；拒绝改脸改课件、重复图、混用尺寸和未验收结果。
- 声明共享 Profile、真实案例、能力组合、定价边界与本地分发状态。
