# Changelog

## 0.1.0 — 2026-11-10

- 首个版本：`scripts/meeting_context.py` 提供 `context` 与 `clean`，用一次不带登录态的请求读取
  腾讯会议元宝笔记分享页（或该页面另存的 HTML），输出带编号的 `notes.md` 与 `context.json`。
- 摘要要点、图文卡片、待办、会中实时笔记分别编号（s / c / t / n）；人名占位符换成昵称，
  账号标识、会议号、房间号不写入任何输出。
- 实时笔记里 AI 的转述与「解读」分开；列出只在实时笔记里出现、摘要和卡片里没有的数字。
- “我”的认定：`--self-name` 完全或部分匹配；没给名字时按笔记归属人推定；给了名字但对不上时
  不退回归属人。
- 只访问 `meeting.tencent.com` 的 https 链接，不跟随跳到其他地址的重定向；链接失效、页面没有
  纪要、不是元宝笔记时给出明确的错误码与下一步。
- 四种协作模式（brief、catch-up、work、follow-up）、三处对齐的做法，以及会议跟进的作者性约束。
- 25 项不联网的回归测试，使用合成的分享页，不含真实会议内容。
