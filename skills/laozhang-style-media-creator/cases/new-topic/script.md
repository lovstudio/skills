# 总替别人的情绪负责，为什么越体贴越累？

以下阿宁的情境为虚构演示，不对应真实人物或来访案例。

## 0.0–8.0 秒

你有没有发现，有时候你不是在和一个人相处，而是在不停地监测他的心情。他少回一个字，你就开始检查自己哪里做错了。

## 8.0–20.0 秒

举个虚构的例子。阿宁约朋友见面，对方回了一句，今天先不聊了。她立刻把聊天记录翻了三遍，想是不是自己太烦了，又补了好几句道歉。可对方还没有说明原因，她已经开始替这段关系收拾残局。

## 20.0–34.4 秒

这可能不只是体贴，而是你把维持关系的责任，全都放到了自己身上。只要你不高兴，我就得做点什么。只要我把你安顿好了，这段关系才算安全。于是，对方的每一次情绪变化，都像一张突然递过来的考卷，而你不能不交。

## 34.4–46.4 秒

但我们先停一下。回复很短，是你看到的事实；他讨厌我，是你加上的解释。对方可能只是忙，也可能确实有情绪，也可能暂时不想说。现在的信息不够，就先不要替他把答案写完，更不必立刻给自己判错。

## 46.4–59.2 秒

关心和负责到底有什么不同？关心是，我愿意听你说，也愿意询问我能做什么。过度负责则是，你还没开口，我就已经认定这件事跟我有关，认定我必须把你变开心。前者是在靠近一个人，后者却让自己一直站在被评判的位置。

## 59.2–76.8 秒

下一次再遇到这样的时刻，可以先做一个很小的区分。第一句，只说事实，他今天回复得比平时少。第二句，说出自己的感受，我有点不安。第三句，再决定行动，我可以问一句你现在方便聊吗，也可以先去做自己的事。注意，是做选择，不是逼自己立刻变得毫不在意。

## 76.8–89.6 秒

如果对方确实不舒服，你可以说，我愿意听你讲，但我现在只能聊十分钟，晚一点我们再继续。这不是冷漠，也不是放弃关系，而是你开始把两个人的感受都放进来了。你可以关心他，同时也不把自己从这段关系里拿掉。

## 89.6–96.0 秒

真正值得练习的，不是让所有人都满意，而是别人有情绪的时候，你依然知道，自己也在这里，也有选择。
