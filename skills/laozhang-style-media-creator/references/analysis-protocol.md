# 参考视频分析协议

## 冻结样本

源文件只读，先记录URL、SHA-256、时长、画幅、编码及音轨。先冻结训练与留出拆分，再做规则选择。当前版本按主页顺序1–8训练、9–10留出。规则支持度的分母为适用训练样本，不含留出。

## 时间证据

完整转写使用听悟原始JSON，保留词与句时间、原始拼写及来源哈希。标准化工具不纠正人名或重写原话；ASR专名与画面文字不一致时记录问题，核对后输出修订副本，不覆盖原始转写。

FFmpeg全片解码测量混合音轨响度、True Peak、静音及硬视觉变化。场景检测采用320px宽、阈值0.23，能漏掉小幅跳切与渐变，不能当全部剪辑切点。混轨静音不是人声VAD；整片ASR字数/片长不是有声段瞬时语速。

每片抽12个分布时间点，额外查看清晰帧；OCR和脸部矩形只用于字幕/构图，不识别人物。字幕坐标为左上角归一化坐标，不跨画幅硬套。精确字体、剪辑软件、光源设备、素材工程参数无法核实就保留未知。

听感分析抽取开头、40%和80%处各15秒，并记录拼接段到源片时间映射。多模态模型只对其实际收到的片段作解释；不能把45秒未听到音乐写成全片无BGM。模型返回文本中自称“测量”的数值仍须对照仪器结果。

## 规则

每条规则包含观察、生成指令、适用条件、证据ID、支持样本ID、分子分母、例外、置信等级与验收方式。字句证据必须精确出自保留的源段；视觉证据指向真实图片；量化证据指向可回读测量。

反复出现是共性，只在部分作品出现是变体或可选项。题材、人名、资质、效果承诺和未证实的心理分析不是可迁移风格。禁止用模型补齐不存在的原片例句或伪造支持数量。

## 留出验证

先冻结画像SHA，再读取留出全文和关键帧，用固定规则检查并记录命中、例外与不适用。定量区间只是诊断，不将超出区间自动判成风格失败。不得据留出结果无记录地调整原版规则。

自动检查与模型/宿主解释分别标记。没有人类参与的盲评不称“人类盲评通过”。有真实新选题脚本与制作计划才形成生成案例；只有提示词和脚手架不算完成。

## 外部服务

采用宿主现有的最高质量生产模型，不自动降级。发送仅限公开/已授权素材。凭据从进程环境读取，禁止写入源包、Profile、URL、日志或案例。401/402等错误须保留脱敏诊断；恢复后只补未完成的分析，不重复提交已完成ASR任务。
