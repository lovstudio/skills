# Skill Group Composition

## Nearby Skills Inspected

- lov-media-crawler：已授权社交链接到已验证本地媒体；本次10条输入来自其真实下载报告。
- lov-style-clone：文章文风提取与改写，覆盖文字而非音画时间协议。
- lov-media-creator：已有素材到剪辑/字幕/混音/渲染验收；本 Skill 不替代完整制作与发布流程。
- lov-skill-creator：可移植Skill脚手架、Profile、验证和本地安装，负责本次封装骨架。
- lov-branding-consistency：创作型用户可见文案的在位审校，作为显式规范依赖。

## Atomic Handoffs

- 可选上游下载：授权链接 → 下载能力 → 原视频、清单、哈希；验收为真实媒体。
- 可选上游ASR：原视频/音频 → 已配置转写服务 → 带时间原始JSON；不得把转写摘要当原话。
- 核心：参考视频及事实brief → 本 Skill → 风格协议、证据、脚本和制作时间线；验收为来源可核验、可执行且结构通过。
- 可选下游制作：已验证时间线与授权素材 → 媒体制作能力 → 实际编码成片；由制作能力负责完整观看、听审与媒体验收。
- 可选下游发布：经用户批准的真实成片 → 发布能力；本 Skill 不自动外发。

## Overlap Decisions

文章文风是一个输入维度，不足以拥有八维声画风格和时间线验收，因此不把本任务伪装成纯文章改写。媒体制作以已有素材成片为验收，本任务以参考风格可迁移为验收，两者通过制作计划交接，不复制完整渲染框架。下载、ASR和发布不成为隐藏运行依赖。

## Composition Decision

Single Skill。提取、创作和检查共享同一风格JSON、证据与时间协议，内部脚本不构成独立用户产品。画像数据与通用测量/验证脚本分离，更新风格不需要复制生成器。没有启动子Agent；可选云模型仅作为显式记录的感知/结构分析调用。
