# Changelog

## [0.1.0] - 2026-11-15

### Added

- 竞品调研四个模块：差异对比、血缘溯源、含金量、投资视角，共用一份证据账本，支持逐级追问。
- `scripts/repo_evidence.py`：`facts`（GitHub 元数据与社区比例、可选 star 抽样）、`history`（起源提交、
  补全零提交月份的节奏、作者别名合并）、`loc`（目录代码量、测试占比、依赖清单）、`lineage`
  （全部历史中的相同文件、特有标识符与名称检索，支持比对源项目全部历史）。
- `references/research-playbook.md`：各模块检查清单、血缘证据等级、热度指标口径与报告骨架。
- 首个真实案例：两个热门开源仓库的血缘与含金量调研（已去除项目名），含负向与正向对照。
