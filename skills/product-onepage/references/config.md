# Product OnePage configuration

## Resolution order

1. Current request and CLI flags.
2. Target repository truth, tokens, and approved assets.
3. `SKILL_PRODUCT_ONEPAGE_BRAND_PROFILE`.
4. `SKILL_PROFILE_PATH`.
5. `${SKILL_PROFILE_PATH:-$HOME/.skill-publisher/skills/profile.json}`.
6. Packaged public Skill Publisher profile.

## Brand profile

```json
{
  "schema_version": 1,
  "name": "Your Product",
  "site": "https://example.com",
  "logo": "./logo.svg",
  "primary": "#24324A",
  "accent": "#EB6637",
  "ink": "#172033",
  "muted": "#667085",
  "paper": "#F7F4EF",
  "font_family": "Inter, PingFang SC, Microsoft YaHei, sans-serif",
  "copyright": "Generated by Your Brand",
  "output_dir": "$HOME/Documents/product-onepage"
}
```

Resolve relative Logo paths from the profile directory and embed the Logo into
HTML. Published Skill source must not contain a personal workspace path.

## Environment variables

| Variable | Meaning |
|---|---|
| `SKILL_PRODUCT_ONEPAGE_BRAND_PROFILE` | Skill-specific brand JSON |
| `SKILL_PRODUCT_ONEPAGE_OUTPUT_DIR` | Default output root |
| `SKILL_PROFILE_PATH` | Shared brand JSON |
| `SKILL_PROFILE_PATH` | Shared Skill Publisher profile |
| `SKILL_OUTPUT_DIR` | Shared output root |

Credentials stay in environment or a credential store. They never enter
project metadata, prompts, HTML, or audit reports.
