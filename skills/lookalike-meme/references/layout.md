# 版式规格

画布固定 1080×1440（3:4 竖版），由 `scripts/render_meme.py` 生成 HTML 后用 headless Chrome 截图。

## 背景

- 纯亮色底（按 `--palette`），叠白色半透明圆点网点：点径约 3px，间距 26px。
- 放射线：以画面 (50%, 55%) 为圆心的 `repeating-conic-gradient`，白 14% 透明度，6° 亮 / 8° 空。

## 贴纸卡片

- 白底、14px 白边、36px 圆角（内图 24px 圆角）、硬阴影 `12px 14px 0 #1a1a1a`，不做模糊。
- 3 张：左上 470² 旋转 -7°；右上 500² 旋转 6°；下中 560×500 旋转 -2°。
- 2 张：左上、右下错位，各 500×560，旋转 -6° / 5°。
- 1 张：居中 700×900，旋转 -3°。
- 默认 `cover` 裁满；参考角色图加 `#contain`，整图缩进白卡并留 6% 内边距。

## 标题

- 只放一个大标题，字体得意黑 SmileySans Oblique。
- 单行字号 = min(190, 980 / 字数)；两行（`|` 分隔）时每行不超过 130px，贴纸整体下移 60px。
- 黄字（黄色底时改白字）、14px #1a1a1a 描边、`paint-order: stroke fill`、硬投影 `10px 12px 0`、整体旋转 -4°。

## 卡通格的生成约束

- 只上传真人照片；参考角色的姿势用文字描述。
- 提示词固定要求：原创角色、不模仿任何版权角色、全身居中约占 80% 画高、纯浅灰底、平涂、无任何文字或水印。
- 默认 1:1；单次约 USD 0.17–0.25（以 OpenRouter 返回的 `usage.cost` 为准，写入账本）。
