# AI 功能 UI 契约

## 先判断是否需要界面

需要用户发起、编辑、选择或确认结果时提供 UI。后台分类、同步或自动摘要则优先以现有页面的状态变化呈现，不额外创建对话框。

## 最小完整交互

1. 将 AI 入口放在用户原本完成任务的位置。
2. 说明能力和输入约束，不说明内部渠道或实现历史。
3. 禁用重复提交，展示进行中的工作状态。
4. 呈现结构化结果和对应的下一步操作。
5. 保留输入并提供重试；错误文案只表达用户可以采取的动作。

## 模型偏好

默认将模型意图作为产品设置。只有“速度 / 深度 / 成本 / 视觉能力”会影响用户决策时，才在界面展示为通俗选项；不要把供应商内部模型标识当作主要 UI。

## 验收

键盘操作、焦点、加载、空状态、失败、重试、窄屏和本地化都属于功能的一部分。
