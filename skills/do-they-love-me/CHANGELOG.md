# Changelog

## 0.2.0

- Skill ID 从 `lov-love-index` 改为 `lov-do-they-love-me`（英文单数 they，
  he／she 通用），展示名仍是「恋爱指数分析」。真源目录同步改为
  `do-they-love-me-skill`，三个宿主软链一并更新。
- 语义标注从「单条模型」升级为「规则层 + 带上文模型」：没有话题的消息
  （系统提示、纯应答、纯表情数字、纯英文碎片）由脚本判掉，其余附上一条上文。
  规则层覆盖全量 10.0%，工作类召回回到 0.90。
- **隐私与口径修正**：提示词里的示例原先是 14 条真实聊天原句，现已全部换成合成句。
  真实原句是第三方对话，不该进入公开仓库；它同时属于同域近邻，会把一致率抬高。
  换句后重跑校准，一致率 77.1%（工作类精度 0.875／召回 0.903），**低于自设的 80%
  门槛**，因此卡面口径行明确写「低于门槛、占比仅供参考」，情感占比只作粗分档。
- 话题构成图补上颜色图例；口径行写明模型名、一致率与「情感占比是粗分档」。
- 修掉周趋势图末周刻度越界被裁的缺陷；`verify_figures.py` 新增逐图
  `clipped_in_svg` 检查，专门抓「内联 SVG 裁掉 viewBox 之外内容」这类
  卡片级审计看不见的问题。
- 早期两版数字作废：85.4% 那版有 4 条示例落在校准集内；81.2% 那版示例是真实原句。

## 0.1.0

- 首次发布：量化互动（回复间隔、开场收尾、深夜、连续天数、媒体构成）＋
  本地语义分层（工作／情感／生活／无内容，含手工校准协议）＋ 三张图形
  （日历矩阵、话题构成、周趋势）与卡片交接契约。
- 明确红线：工作内容不计入情感热度；自定义指数必须公开权重且不得称为情绪测量；
  语义占比必须同时给出模型与一致率；第三方隐私默认只在本机处理。
