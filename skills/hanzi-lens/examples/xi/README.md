# 「翕」标杆案例

这个案例只解释“翕”字本身。

核心结论：

> “翕”不是静止的闭合，而是起飞前的敛翼：收束之中，自有聚合与和协。

## 证据路径

```text
《说文》“起也”
      +
段玉裁“鸟将起必敛翼也”
      ↓
   敛翼而起
   ↙   ↓   ↘
收束   聚合   和协
《周易》《广韵》《诗经》《论语》
```
