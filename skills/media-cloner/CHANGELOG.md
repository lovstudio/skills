# Changelog

## 0.1.0 — 2026-11-09

- 把两次手工博主风格复刻（老张心理、晓暖说媒）的方法整理成通用流程：选样、分析前冻结拆分、只测训练集、规则草稿、构建、校验、冻结、留出检验、说明书。
- `cloner.py`：由规则草稿构建风格包；引文在转写中精确定位，支持数由证据推出，拒绝留出证据与越界分母。冻结记录画像、证据与拆分的 SHA-256，冻结后改动会被发现。
- `measure.py`：全片测量、OCR 版式扫描（区域发现与颜色聚类）、提示音扫描、本地转写与 Whisper/听悟/SRT 导入、说话人提示。画像冻结前拒绝处理留出样本，避免晓暖 v0.1 的留出污染再次发生。
- 留出检验要求每个“规则 × 留出样本”都有结果，受污染项与独立结果分开汇总。
- 参数驱动的 Remotion 模板（`StyleClip`、`StyleCover`）与通用音轨构建 `build_audio.py`。
- 在晓暖研究数据上的复现结果：
  - 画像与证据文件和 v0.1 冻结包逐字节一致；
  - 测量、OCR、提示音与训练集分布与原值一致；
  - 模板填入晓暖参数后与专用模板逐像素一致；
  - 音轨复现演示音轨（-15.71 LUFS，相关系数 0.9998）。
- 校验器兼容老张 v0.1 的旧证据类型，两个已发布的风格包都能通过校验。
