# 风格分析协议

## 产物

一份风格包是一个版本目录（如 `style-pack/SLUG-v0.1/`），包含：

- `style-profile.json`：样本清单与拆分、八维摘要、规则、指标分布、叙事/版式模板、声画触发、禁用清单、局限与来源说明。字段形状与 `lov-laozhang-style-media-creator`、`lov-xiaonuan-style-media-creator` 的风格包相同，下游可直接复用。
- `evidence.jsonl`：每行一条证据（原话、测量或画面），带样本 ID 与时间码。
- `measurements/`：只含训练样本的文本测量副本，不含帧、截图或音频。
- `per-video-analysis.json`、`build-report.json`、`FROZEN.json`、`holdout-report.json`。

原片、抽帧、截图、完整转写只留在工作区的 `research/`，不进入风格包以外的任何产物。

## 顺序与门禁

1. 定格式期与候选清单。
2. 选样，并在任何测量之前定好留出。
3. 下载与登记：`register` 写入 SHA-256、时长、画幅、编码。
4. `freeze-split`：拆分摘要写入 `sources.json`，之后改样本、换文件、调拆分都会让工具拒绝运行。
5. 只测量和转写训练集。
6. 通读训练集，写阶段标注和规则草稿。
7. `build`、`verify`、`freeze`。
8. 用 `--frozen` 打开留出集，逐条检验规则。
9. 写说明书；可选做模板、演示与封装。

脚本会强制执行第 4、5、7、8 步的顺序：测量工具对留出集的请求在冻结前一律拒绝，冻结包被改动后也会重新封存。不要绕开这些门禁，例如手工对留出文件跑 FFmpeg。

## 冻结样本

样本框必须写明：

- 格式期（`era_scope`）；
- 选择方法（`selection`）；
- 权利边界（`rights`）。

规则的分母只计入适用的训练样本，留出样本永不进入规则选择。样本少于 6 条时说明代表性有限，状态写 `ready_with_limits`。

## 时间证据

- **完整转写。** 保留原始 ASR 输出和规范化后的 `media-cloner-transcript/v1`。专名、口音造成的误听按原样保留，在 `limits` 里记录，不在引文里纠正。
- **原话证据。** 必须是转写里的精确子串。`build` 按时间提示在前 12 秒、后 35 秒的窗口内定位；在窗口外找到会给出警告，找不到就拒绝。

全片测量（`measure.py media`）的方法和局限：

| 测量 | 方法 | 局限 |
| --- | --- | --- |
| 剪辑点 | 320 px、场景阈值 0.23 | 漏掉轻微跳切与渐变，不能当全部剪点 |
| 静音 | silencedetect -35 dB / 0.2 s | 测的是混合音轨，不是人声 VAD |
| 响度 | loudnorm 测整片响度与真峰值 | |
| 抽帧 | 固定时间点抽帧，生成接触表 | |
| 听感片段 | 开头、40%、80% 各 15 秒拼成 `audio-sample.mp3` | 只能据此判断收到的片段，不能推断全片有无配乐 |

## 画面与版式

`measure.py layout` 每 2 秒抽一帧，用 macOS Vision 做 OCR：

- **坐标。** 左上角为原点，按画面归一化，不跨画幅硬套。
- **版式区域。** 先用 `--discover` 看文字框在画面上下的分布和出现率，再为该博主写区域配置（标题、字幕、资料卡等）。默认区域只适合 9:16 口播。
- **颜色。** `--colors` 对文字框像素聚类，给出主色与占比。哪一簇是填充、描边或背景，由人看图判断。
- **字体与软件。** 精确字体、剪辑软件、工程参数无法核实，记为未知，不写成规则。

## 声音

- **测试音与哔声。** `measure.py tones` 找指定频段的测试音或哔声（默认 1 kHz），用来定位分隔与拼接。它只听声音，必须回到画面确认。
- **背景音乐。** 有无配乐、配乐类型靠听感片段和人工判断。音乐与人声的电平关系可在分离后测量，但分离步骤不在本 Skill 内。
- **说话人。** `measure.py speakers` 用高频能量比做二聚类，只作提示；角色以阅读判断为准，说话占比不作规则依据。

## 规则

- **字段。** 每条规则写观察、生成指令、强度、证据、支持样本、适用分母、置信、范围、例外与验收方式。
- **共性与变体。** 反复出现的是共性，只在部分子类型出现的是变体或可选项。
- **不可迁移的内容。** 题材、人名、资质、服务承诺、收入或案例数、未证实的市场判断与刻板说法，写进 `guardrails`。
- **不确定项。** 写进 `limits`，不写成规则。

## 留出验证

1. **冻结后才读留出。** 冻结后用 `--frozen` 转写、测量留出样本，通读全文、看抽帧。
2. **规则照原文套用。** 每个“规则 × 留出样本”都记录 hit / partial / miss / not_applicable；partial 和 miss 要写说明。
3. **处理污染。** 冻结前在批量日志里见过的留出数值，标 `contaminated: true` 并写来源，汇总时与独立结果分开。
4. **修订进下一版。** 基于留出的修订写进 `suggested_revisions`，进入下一版本，重新选留出。定量区间只作诊断，超出区间不自动判失败。

## 外部服务与权利

- **素材范围。** 只处理公开或已授权作品；不绕过付费、私密或已删除内容；不收集评论区个人信息。
- **凭据。** 只从进程环境或系统凭据存储读取，不写入工作区、风格包、Profile、日志或案例。
- **云端处理。** 调用云端 ASR 或多模态模型前，说明会发送哪些素材。
- **转授边界。** 风格包只描述手法。原片、人像、声音、台词、截图、封面与品牌标识的权利不因分析而转授。
