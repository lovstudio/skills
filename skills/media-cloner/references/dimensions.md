# 八个维度

风格包固定用这八个维度。每个维度都要写一句摘要；没有可靠规则的维度，就在摘要里写明原因，并在 `limits` 中记录，不硬凑规则。

| 维度 | 看什么 | 主要证据 |
| --- | --- | --- |
| `thinking` 思维 | 作者怎样定义问题、用什么坐标下判断、怎样改写对方的问题、结论落在哪里 | 原话（通读后选） |
| `narrative` 叙事 | 开场方式、阶段顺序与占比、转折、收束、是否有前置高光、系列或引流结构 | 阶段标注 + 原话 + 时间码 |
| `language` 语言 | 高频词与术语、句式（“不是 A 而是 B”、编号列举）、称呼、口头禅、追问长度 | 原话 + 词频测量 |
| `delivery` 表达 | 语速（每分钟文本单位）、停顿、互动形式（连麦、问答、独白）、语气起伏 | 转写测量 + 听感片段 |
| `visual` 画面 | 景别与构图、机位、光线与场景、画中画、道具、B-roll 比例 | 接触表 / 抽帧 + 描述 |
| `subtitles` 字幕与屏幕文字 | 标题块、字幕位置与行数、每行字数、标点、高亮、颜色、资料卡、字体类型 | OCR 版式测量 + 抽帧 |
| `editing_audio` 剪辑与声音 | 硬切频率、镜头时长、分隔与转场、配乐与音效、整片响度与真峰值、静音占比 | 全片测量 + 提示音扫描 + 听感 |
| `coupling` 声画耦合 | 画面、文字、声音怎样响应说话内容：标题停留到哪句、资料卡何时出现、提示音落在哪个剪点 | 时间码对齐的组合证据 |

## 怎么写好一条规则

- **观察写可复查的事实。** 例如“10 条里 8 条在 7–18 秒处有 0.75–1 秒彩条和 1 kHz 提示音”，而不是“节奏紧凑”。
- **指令写下一个 AI 能执行的动作。** 例如“第一段放 5–20 秒的前置高光，完整句首句尾，正片原位再出现一次”。
- **分母写适用的训练样本。** 只在连麦个案里出现的手法，分母就是连麦个案数。
- **例外写具体样本与原因。** 不要用“偶尔”“部分”带过。
- **验收方式写成门禁。** 能自动检查的给阈值，只能人工判断的写清楚看什么。

## 迁移边界

可以迁移：

- 推理路径、叙事结构、句式、节奏、版式参数、剪辑与声音手法、声画对应关系。

不可迁移：

- 作者身份、名字、头像、口头签名与栏目名、品牌字样与道具文字；
- 服务承诺、收入与案例数；
- 原作中的市场判断、性别或职业刻板说法；
- 原片、截图与原话本身。新作品里的原话必须来自新作者自己的素材。

## 常见误判

- 把一次性的选题特征当风格（题材不是风格）。
- 把爆款的偶然元素当共性：分层抽样和分母会暴露这一点。
- 用混合音轨的静音占比代替说话停顿。
- 用场景检测的剪点数代表全部剪辑（漏掉跳切）。
- 根据 OCR 的字框高度断定字号与字体（描边会放大字框）。
- 听了 45 秒就断言全片无配乐。
