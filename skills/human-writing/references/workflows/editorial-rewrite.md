# Editorial Rewrite Workflow

这是 `lov-human-writing` 的内部改写阶段，只修改能由账本、篇章报告或表层靶点解释
的地方。

## 步骤

1. 先处理命题来源、因果、反例与收束等结构问题，再处理句词表面。
2. 默认局部编辑；只有结构证据要求时才重排相关章节。
3. 精确保留事实、术语、引语、立场、确定程度、作者声音与有意留下的问题。
4. 不统一套用现场开头、定义拆解、价值回归或行动号召。
5. 不新增错别字、口头禅、情绪、无关细节或“真人噪声”。
6. 在内部记录“问题 → 修改 → 依据”，供复测使用。

当本阶段由 `lov-writing-style` 调用时，个人文风画像属于受保护输入。表层指标与已
校准作者声音冲突时，保留作者声音并记录理由。
