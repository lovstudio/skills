# Changelog

## 0.1.0

- 公众号博主文字风格克隆流水线：`lov-wxmp-cli` 导出或 Markdown 目录导入、基线语料、阅读前冻结拆分、训练集度量、逐字证据的八维规则构建与校验、冻结。
- 盲测与留出检验：标题/摘要简报、画像稿与对照稿登记、解封后逐条标注、汇总度量带吻合、人工盲评配对与记分。
- 中文感知的 `stylometry.py`：句段节奏、标点、人称、英文与数字密度、标志短语（相对基线倍率）、固定段落、度量带审计、哈希指纹原文重合检测、身份标识检测。
- 封装为专属写作 Skill：与 `lov-skill-creator` 骨架衔接，写入风格包、写作协议、卡片与盲测案例，封装时对作者联系方式脱敏。
- 首个真实案例：公众号「数字生命卡兹克」。
