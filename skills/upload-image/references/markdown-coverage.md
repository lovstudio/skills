# Markdown Image Coverage

## Rewritten forms

| Form | Example | Behavior |
|---|---|---|
| Inline Markdown | Image syntax with destination `images/a.png` | Replaces only the destination. |
| Angle destination | Image syntax with angle-wrapped destination `images/a b.png` | Preserves angle brackets around the URL. |
| Image reference | `![alt][hero]` plus `[hero]: images/a.png` | Rewrites the used image definition. |
| HTML image | `<img src="images/a.png">` | Replaces only the quoted `src` value. |
| Obsidian embed | `![[images/a.png|caption]]` | Converts it to standard Markdown with the caption as alt text. |
| File URL | `file:///path/to/a.png` | Resolves and uploads the local file. |
| URL-encoded path | `images/a%20b.png` | Decodes the local filesystem path before upload. |

Paths relative to the Markdown document are resolved from the document's parent
directory, not the caller's working directory.

## Preserved forms

- HTTP and HTTPS URLs, protocol-relative URLs, `data:`, `blob:`, FTP, mail, telephone,
  and anchor references.
- Markdown image-like text inside fenced code blocks or inline code spans.
- Ordinary Markdown links and reference definitions that are not used by an image.
- Image title text, alt text, HTML attributes other than `src`, and surrounding prose.

## Safety behavior

The entire document is scanned before upload. Every discovered local path must resolve
to a regular file. One missing file stops the run before any image is uploaded.

Identical resolved paths are uploaded once per run even when referenced in several
forms. Replacements are applied by source offsets only after PicGo returns a complete
one-to-one mapping. Writes use a temporary file plus atomic rename.

New-file mode is the default. In-place mode creates a sibling `.bak` file unless the
caller explicitly supplies `--no-backup`. Existing output or backup files require an
explicit `--force`; callers must inspect the exact target before using it.

## Deliberate exclusions

- CSS `url(...)`, HTML `srcset`, frontmatter image fields, and images generated by
  runtime templates are not rewritten automatically because their parsing rules are
  context-dependent.
- Unquoted HTML `src` attributes are not rewritten.
- Remote-to-remote migration is not included; the input must be a local file.
