# 非交互预检

启动时先执行 [当前 session 权限准备](session-permissions.md)，复用已有权限，并通过正式允许的接口配置任务必要权限。

此预检是每个可能写入、调用外部服务或长时间执行的动作前的轻量判断，不是发给用户的问卷。

| 情况 | 执行策略 | 记录状态 |
| --- | --- | --- |
| 范围、目标、权限明确且现有工具可直接执行 | 执行并回读 | running → completed |
| 只缺少可逆实现选择 | 按请求、项目、配置、偏好与默认值推断 | assumption |
| 缺少不可推断的事实或真实素材 | 完成独立部分，保留依赖 | deferred_input |
| 操作已获授权，工具仍要求人类审批 | 不发起已知会停住的调用；准备本地制品 | deferred_authorization |
| 操作本身未授权 | 完成所有可执行准备，不擅自扩大范围 | deferred_authorization |
| 自动审批已拒绝 | 保留动作与拒绝原文，不重试等价绕过 | deferred_authorization |
| 命令需要登录、密码、验证码或首次配置 | 不触发登录向导；复用已授权连接，否则延期 | deferred_input |
| 网络短暂故障 | 检查原因，默认至多两次有依据重试 | retrying / deferred_external |
| 远端写入超时、结果不明 | 用请求标识或业务对象回读；不能直接重复写入 | unknown_outcome |
| 所有剩余步骤受阻 | 保存具体恢复条件并结束本轮 | partial / blocked |

优先官方 CLI/API 的只读检查、状态查询、dry-run 和非交互选项；只有已授权且语义明确的
常规参数选择可以预填。不得用自动 yes、免审批参数或改配置吞掉安全确认。

预检只能减少可预见的等待，不能证明未知宿主工具不会弹审批。
若工具进入 pending approval 且宿主把 Agent 一起暂停，本 Skill 无法在暂停期间运行，
不能承诺会自动解锁。能安全取消的仅取消本任务自身待批请求，不能操作用户其他队列。

普通子进程需要输入时，优先工具明确支持的非交互失败模式；可用时关闭标准输入并设置
合理超时。输出 pending 不算成功；长任务启动后保留实际会话或作业 ID，并使用宿主等待
机制，避免忙轮询。不得把安装、登录或许可失败改写成成功。

一个拒绝并不允许扫描其他凭据、改用其他身份或将同一被拒动作发给另一工具。允许的
替代路径必须有独立授权并尊重相同保护边界，例如发布受阻后生成本地预览。

已获授权的站立规则只在证据完整时复用：触发条件、对象、载荷、目的地、范围和有效期
或终止条件都要从用户记录查明。偏好不是权限；当前撤销优先于历史规则。
