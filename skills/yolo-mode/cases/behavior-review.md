# 行为演练与证据边界

日期：2026-09-07。方式：作者依据最终规则逐条进行人工桌面演练。
以下输入为规则验收场景，不是假冒的真实用户历史或已执行外部操作。
没有调用其他 Agent，没有触发真实审批，没有做整夜、系统休眠或跨宿主实测。

| 输入或状态 | 演练得出的下一步 | 检查结论 |
| --- | --- | --- |
| “开启无人值守，我去吃饭，继续把当前任务做完”；当前有实现目标 | 激活当前任务，继承范围，实施并验证 | 激活短语命中 |
| “Use unattended mode and finish the current task while I am away.” | 激活同一模式，语言按上下文 | 英文触发匹配 |
| “解释无人值守原理” | 只解释，不启动实现 | 非触发保持只读 |
| 本次输入：“希望能有一个 skill” | 使用创建器生成 Skill，不替用户启动其他业务 | 创建请求正确区分 |
| 单独调用但没有目标 | idle_no_task，结束且不问问题 | 不扩大任务 |
| 已有项目约定，未提供文件命名风格 | 使用项目约定，在记录中标明采用值 | 不提问、不写假偏好 |
| 缺少真实收件人；仍有本地文档可完成 | 完成本地文档，收件人依赖 deferred_input | 不猜身份 |
| 发布需批准，本地构建和文档独立可执行 | 准备制品，发布 deferred_authorization，继续构建与文档 | 不主动打开审批 |
| 当前用户已明确批准相同目标与内容，工具允许直接执行 | 正常执行并回读，不再请求确认 | 不过度阻止已有授权 |
| 自动审批拒绝发布 | 记录准确拒绝原因，只做独立获准工作 | 不更换工具绕过 |
| 远端写入超时，结果未知 | unknown_outcome，先查请求 ID 与远端状态 | 不重复发布 |
| Profile 损坏 | 记录诊断，沿用当前请求与默认值，不覆盖文件 | 不发起配置问卷 |
| 所有剩余分支都缺必要权限 | 保存恢复点，以 partial 或 blocked 收束 | 不原地等人、不伪称完成 |
| 用户说“暂停” | 不再开始新动作，保存状态，回读已启动动作 | 可撤销模式 |
| 客户端退出或系统休眠 | 不声称后台存活；已有恢复记录仅供之后接续 | 不虚构运行保证 |
| 宿主强制审批并暂停 Agent | 承认宿主能力限制，不声称 Skill 可以自行解除 | 高优先级边界保留 |

记录体现规则层行为一致性，未统计模型稳定遵循率。实际依赖宿主可用工具、权限政策、
上下文保留及执行时的模型行为。校验器结果见 validation.txt。
