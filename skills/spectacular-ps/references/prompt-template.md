# 身份与场景明确的 Prompt

先实际看图，将以下说明替换为当前照片事实；最终 Prompt 不留模板槽位。

```text
将原图编辑成写实、有电影感的环境人像。用途是当前用户要求的头像或照片。

图片角色：逐一指明原图、仅供风格参考的图片、已否定版本和选定成片。
原图是 edit target 和唯一 identity source。只借鉴参考图的构图、光影、调色与气氛，
不复制参考人物、服装、姿态或地点；不使用被否定版本的错误景别。

人物保留：根据原图列出脸型、五官比例、神态、肤色、发型或帽子、眼镜、衣服、配件、
姿势和身体比例。不要换脸、瘦脸、改变年龄或过度磨皮。

构图：写清画幅、景别、人物位置、展示到身体何处、环境占比及视觉重心。
头像模式保持脸和躯干在圆形安全区，避免为了放大全脸而丢失环境尺度。

场景保留：根据原图列明天气、主要地形/地标、前景物件及空间关系。
仅允许执行用户明确要求的结构改动；没有授权时只做裁切和真实摄影后期。
如已授权艺术化处理，逐项写出允许新增、删减或重构的元素，并限制范围。

光影与色彩：按原片或参考风格写明色温、阴影、高光、背景杂色和面部亮度。
肤色自然，衣服保留纹理，人物与背景光向一致，边缘不出现抠图感。

避免：塑料皮肤、过度锐化、夸张 HDR、解剖错误、重复配件、擅自换装、无授权改天气。
输出单张成片；不添加文字、Logo、水印、边框或额外道具。
```

复刻交付以实际执行的 Prompt 为准；后续修正也记录其变化。工具未暴露的参数标记
不可用，不捏造 seed、精度或模型版本。图片顺序必须和实际调用一致。

仅借用风格的海边回归场景：红色外套、站姿、灯塔和原天气保持；雪山参考只能贡献环境
尺度与光影组织。不能把海边改成冰川，不能移植参考图的黄衣跪姿。
