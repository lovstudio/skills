# 原图与成片的真实对比

对比使用两个已存在、可读取的真实文件。左原图、右选定成片；不选被否定的近景稿或风格
参考。原文件保持不变。

1. 用 SHA-256 绑定来源，先回读确认图像角色。
2. 使用 `scripts/compare_images.py` 排版。统一展示高度，宽度随原比例计算，完整 contain。
3. 输出 PNG、适度留白、无装饰图标/箭头。默认无烧录标签，交付中说明左原图/右成片。
   中文标签如确有需要，在图片之外用已验证中文字体的排版工具添加，不重绘照片。
4. 回读输出尺寸与 JSON 中的面板位置，确认没有裁切、拉伸或内容生成。

工具应用 EXIF 方向并将有效嵌入 ICC 转为 sRGB；无配置文件按 sRGB 处理并记录。
等高排版意味着确定性重采样，透明度在中性底色上展平。因此应称“真实文件拼接”，
不能称“像素完全未变”。颜色配置无效则报错，不静默伪称颜色已校准。

缺原始文件但聊天中能显示两张图片时，可分别展示并说明无法验证精确拼接。不能让图像
生成工具重新画 BEFORE 面板；历史生成式对比只属排版示意，不是像素保真证据。

CLI 仅用于用户要求的比较排版。照片主体编辑仍交给原生图像工具；宿主禁止本地排版时
遵守宿主边界，分别展示已有图片，不绕过限制。
