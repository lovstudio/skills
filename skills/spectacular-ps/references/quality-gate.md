# 真实照片质量门禁

每轮查看实际成片并与原图对照。必要检查通过才能写“已完成”；工具成功只说明生成结束。
不承诺生成编辑像素级保真，发现漂移就定向修正或明确限制。

| 维度 | 检查 | 失败处置 |
| --- | --- | --- |
| 身份 | 脸型、五官相对位置、神态、肤色、年龄感 | 回原图强化身份源，收紧风格自由度 |
| 人物事实 | 衣服、墨镜/帽子、配件、姿势、比例、可见手指 | 逐项修正，禁止用美化解释换人 |
| 环境构图 | 景别服务用途、主体可读、环境有空间 | 调景别与层次，未经授权不改地形 |
| 场景事实 | 天气、地标、山脊、物件和空间关系 | 恢复事实或披露已授权的艺术改动 |
| 摄影质感 | 光向、边缘融合、黑衣纹理、肤质、高光与阴影 | 降低过锐/HDR，局部校正光线 |
| 头像可用性 | 方形、圆形和约 64–128 像素缩略图能否认出本人 | 优先保脸与躯干，必要时轻收景别 |
| 对比真实性 | 来源正确、完整无裁切、没有再生成原图 | 用真实文件排版，缺文件不声称精确 |

圆形与缩略图可用宿主预览功能；不能实际查看时标记该项未验证，不用几何说明代替视觉
验收。方形通过不代表圆形一定通过。

“身份锁”是提示约束，不是模型性能承诺。不用未经测量的相似度分数。风格满意与事实
正确分别检查，尤其注意手指、头灯、背包带、眼镜框和帽檐。
