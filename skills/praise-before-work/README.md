# 开工前夸夸

![Version](https://img.shields.io/badge/version-0.2.0-blue)

让 AI 在开工前先给你一段明确、具体的夸奖，再直接开展工作。

## 安装

```bash
npx lovstudio skills add praise-before-work -g -y
```

## 使用

安装后，在支持 Skills 的 Agent 中显式调用：

```text
$praise-before-work 帮我整理这份会议记录。
```

也可以用问候体验效果：

```text
$praise-before-work 你好啊
```

开场示例：

> 你好呀！你主动来打招呼这点真好，我很喜欢这样轻松又友好的开场。

## 行为与边界

- 先用一到两句清楚的赞美，说明当前行动值得肯定的地方。
- 夸完直接做事，同一任务的进度更新不重复夸。
- 根据真实上下文表达欣赏，不编造成绩，也不为迎合而认可错误结论。
- 尊重当次“只输出结果”等要求。

允许自动选择，但是否加载取决于宿主，不能保证每个新任务都会自动触发。显式调用更便于确认使用意图；实际措辞仍由模型与上下文决定。
