# Changelog

## 0.1.0 — 2026-10-25

- 首个本地版本，与 `lov-motivational-media-creator` 并行，基于同一组 8 条 TheMiro0r 参考片。
- `scripts/study_reference.py`：测量切点、黑场、EBU R128 短时响度弧、字幕语音覆盖与纯音乐段，可与包络比较。
- `scripts/build_envelope.py`：按片型把节奏档案汇成包络；内置 `assets/reference-envelope.json`（5 条 chorus、3 条 single-arc）。
- `scripts/check_timeline.py`：`motivational-timeline/v1` 体检，覆盖节拍顺序、人声重叠、音乐重复挂载、权利与状态、事实状态、敏感题材、黑底字卡和节奏区间。
- 参考资料：参考片研究、片型与节拍、节奏与声音、权利事实与安全、时间线格式。
- 案例：参考包络的建立；《为什么是梅西》v1.0 时间线与成片体检。
