# 片型与节拍

两种片型都来自 [参考片研究](reference-study.md)。时间比例是参考片的大致落点，用来排初稿，不是硬指标；材料本身决定每拍长短。

## 节拍角色

`check_timeline.py` 认识这些角色：

| 角色 | 作用 |
|---|---|
| `cold-open` | 片名之前一段自成一体的戏（可选） |
| `hook` | 第一句：主人公的一个判断，或一个让人想看下去的画面。不要日期，不要背景介绍 |
| `title` | 片名（可选；放开头 10 秒内，或作为最后的落款） |
| `setup` | 主人公是谁、他许下了什么（可选） |
| `wound` | 真实的“倒下”：失败、伤病、被否定、失去 |
| `abyss` | 最低点（可选）：最安静的一段 |
| `turn` | 回头的那个决定或那个人 |
| `climb` | 往回爬：一次次尝试、加码的压力 |
| `peak` | 决定性时刻：比赛、发布、上台、回到原地 |
| `echo` | 回到关键时刻的第二次出现（可选） |
| `address` | 主人公对观众说话：为什么讲这件事（可选） |
| `coda` | 收尾：安静，一句话，或一个长镜头 |
| `end-card` | 落款、数据、Logo、求助信息 |

顺序规则（脚本会查）：第一个故事拍是 `hook`，最后一个是 `coda`；`wound` 在 `turn` 前；`wound`、`turn`、`climb` 都在 `peak` 前。

## 单人逆转 `single-arc`

必需：`hook`、`wound`、`turn`、`peak`、`coda`。参考片 226–268 秒。

| 拍 | 大致位置 | 写法 |
|---|---|---|
| hook | 0–8% | 主人公一句话的判断，或别人讲他的一个轶事。STAY 开口第一句就是全片的命题 |
| setup | 8–25% | 他曾经说过、许下过什么。Ali 那条先让他夸下海口，后面的跌落才有分量 |
| wound | 到 30% 左右 | 一件一件具体的失去，用本人的话讲。不总结成“他经历了低谷” |
| abyss | 30–45% | 最低点，最安静。涉及自杀或自伤时按安全规则处理 |
| turn | 40–55% | 回头的那个决定、那个人、那句话。必须有出处 |
| climb | 55–70% | 加码：新的对手、新的质疑。可以再跌一次 |
| peak | 70–90% | 决定性时刻；有现场解说就用现场解说。最响的地方落在这里或紧随其后 |
| echo | 峰内或峰后 | 把 wound 里出现过的那个画面再放一次，这次是“起来” |
| address | 峰后 | 主人公对观众说为什么。没有本人原话就不写这一拍 |
| coda | 最后 8–15% | 安静；一句话；或一个 30–40 秒的长镜头 |

声音来源：

- **原话为主**：本人采访、发布会、现场解说串起来，旁白只在原话接不上的地方补一句事实。
- **旁白贯穿**：原话很少时，原创旁白讲事实，转折、峰、结尾三处必须是本人原话。
- 两种都不允许旁白压在原话上。

画面来源：

- 本人的影像（比赛、现场、家庭影像、作品）优先。
- **平行主人公**：本人影像不够时，可以用一个处境相通的画面线（另一个人、一个物件、一条路）陪着声音走，前提是素材本身有权使用。画面不能冒充是主人公本人。
- **字面化比喻**：主人公讲比喻时，画面直接演那个比喻，一两个镜头即可。

## 多声部 `chorus`

必需：`hook`、`wound`、`climb`、`peak`、`coda`。参考片 303–663 秒，品牌用途建议压到 3–4 分钟。

| 拍 | 大致位置 | 写法 |
|---|---|---|
| cold-open | 0–5%（可选） | 一段自成一体的小戏 |
| title | 0–5% | 小字，落黑或压在画面上（看 Profile） |
| hook | 5–15% | 第一位说话人的命题句 |
| wound | 15–35% | 几位说话人分别讲各自的“倒下”，一人一件具体的事 |
| climb | 35–75% | 接力加码；中间留一段 ≥8 秒的纯音乐作为“谷” |
| peak | 75–92% | 宣言段，人声越来越密，然后人声退出，音乐单独推到最响 |
| coda | 最后 3–8% | 一句收尾的话；或把片名放在这里当落款 |

声音来源：多位真实人物（团队成员、用户、社区里的人）各自的原话，事先取得同意。参考片那种从别人的演讲和电影里剪句子拼起来的做法不可用。

## 两种收尾

- **停在高处**：峰之后只剩一句话和落款，结尾仍很响（参考片 4/8）。
- **落回安静**：峰后撤掉音乐或压低，留现场声、一句话、一个长镜头（参考片 4/8）。

叙事结尾不必等于最响的地方；高潮可以早于结尾，之后回到人。

## 节拍表交付格式

给用户批的节拍表每行写：角色、起止时间（估）、这拍要让观众知道什么、用哪段原话（出处编号）、强度 1–10、音乐在做什么。
强度曲线要有谷：峰前至少一拍比前面低 2 级以上。
