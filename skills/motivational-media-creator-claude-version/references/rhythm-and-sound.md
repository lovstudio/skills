# 节奏与声音

交给渲染执行器的规则。数字来自 [参考片研究](reference-study.md) 与 `assets/reference-envelope.json`。

## 响度曲线

1. **开场安静。** 开场十分之一比峰低 12 LU 以上（参考 12.5–25.8）。开场可以只有现场声或一个乐器。
2. **峰在后段。** 最响的 10 秒放在片长 72%–95%。
3. **峰前留谷。** 峰之前至少一段明显回落（参考多数 ≥4 LU）：拉掉配乐的鼓、只留一件乐器、或干脆只留现场声几秒。
4. **峰留给音乐。** 人声说完宣言或决定性时刻的解说之后，让音乐单独走 8–30 秒，把最响的地方放在这段里或紧挨着它。
5. **宽动态。** 成片 LRA 目标 ≥10 LU。交付整体响度可以照平台要求（如 −16 LUFS），但不要靠全程压缩来达到：先让安静段真的安静，再用峰把整体拉上去。
6. **收尾二选一**：停在高处，或撤掉音乐落回安静（见 [片型与节拍](archetypes-and-beats.md)）。

## 音乐

- 每首歌一条连续音乐床，从选定的入点一直放到出点；不按镜头切碎、不重复挂载。
- 全片最多换一次歌，换歌处放在 `turn` 或 `climb` 开始的地方。
- 剪辑点对音乐结构：峰对准歌里最满的段落；“谷”对准歌里的安静段（间奏、近乎无声处）。先听歌、标出段落，再排时间线。
- 旁白下压低配乐 10–14 dB；原话或现场解说下压得更多（解说常要 18–22 dB），以听清为准。
- 配乐结束后不再补音乐。

## 人声

- 旁白与原话不重叠；两段原话之间交叉淡化 ≤0.15 秒。
- 中文旁白每秒 4–5 字。参考片英文有声段内 157–223 词/分。
- 语音覆盖：单人逆转参考 0.69–0.96，多声部 0.66–0.89。旁白片会更低，低于 0.6 要检查是不是空了太多。
- 原话保留原语言，配中文字幕；字幕说话人要清楚，不让一个人的话压在另一个人的镜头上。

## 剪辑节奏

- 镜头中位 0.8–3.0 秒。
- 两种推进：越剪越快（最后四分之一的平均镜头长是开头的 0.2–0.5 倍），或在结尾用一个 30–40 秒的长镜头。
- 段落之间可以短暂落黑换气；全片的黑场不要变成独立的文字卡（看 Profile 的 `black_title_cards`）。
- 关键时刻需要时出现两次：第一次是倒下，第二次是起来。

## 画面

- 由暗到亮：前中段压暗、低饱和；峰或收尾转到日光、开阔处。
- 片名小、安静，开头 10 秒内或放在最后当落款。
- 画面字幕只压关键词，不写“日期 + 一句话”的碎片说明。日期如需要，做成画面一角的小标注。
- 主人公说话时尽量给他的画面；用平行主人公时，不让观众误以为画面里的人就是说话的人。

## 交给执行器的清单

- `timeline.json`（已通过 `check_timeline.py`）
- 旁白稿与每句的目标时长
- 音乐段落标注（入点、谷、峰、出点）
- 强度曲线（每拍 1–10）
- 混音目标：旁白下压低值、原话下压低值、交付整体响度、真峰值上限、LRA 目标
- 片尾：落款、Logo 来源、求助信息（如需要）

## 成片复测时看什么

`study_reference.py --envelope` 的 `comparison.outside` 里常见的几项：

| 偏出 | 常见原因 | 处理 |
|---|---|---|
| `loudness.lra_lu` 偏低 | 全程压缩，安静段不够安静 | 降开场、谷的配乐与现场声，峰保持 |
| `arc.opening_vs_peak_lu` 不够负 | 开场太满 | 开场去掉鼓点或推迟配乐入点 |
| `arc.pre_peak_dip_lu` 太小 | 没有谷 | 峰前留一段只剩一件乐器或现场声 |
| `speech.coverage` 偏低 | 旁白片、纯音乐段多 | 检查纯音乐段是否都有画面在讲事 |
| `speech.long_breaths` 偏多 | 单人片用了多声部的呼吸 | 有意为之就记理由 |
| `shots.q4_over_q1` 大于 1 | 后段变慢 | 是长镜收尾就保留，否则收紧后段 |
