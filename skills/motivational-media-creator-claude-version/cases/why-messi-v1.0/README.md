# 案例：体检《为什么是梅西》v1.0

2026-10-25 创建本 Skill 时的自测，不是用户单独发起的任务。对象是用户已交付、待看片的 v1.0 横版（3:52，单人逆转、原创旁白贯穿、本人原话放在转折处）。只读：没有改动该项目的任何文件。

## 输入

- 项目时间线 `projects/why-messi/work/v10/edit/timeline-draft.json`（在手工川内容创作仓库内）
- 项目 brief 里的“结构与情绪弧线”表，用来给各段标节拍角色
- 成片 `手工川-为什么是梅西-横版16x9-2026-10-25-v1.0.mp4`

## 做了什么

1. `adapt_timeline.py` 把项目时间线改写成 `motivational-timeline/v1`（`timeline.json`）：59 个镜头、20 句旁白、8 段录音人声、1 首配乐、34 个素材；现场人声垫底不算人声；素材权利按用户“二创风险自担”的表态记为 `risk-accepted`。
2. `check_timeline.py timeline.json --envelope ... --forbid-black-cards` → `check-report.json`。
3. 用时间线里的人声时间导出 VTT，`study_reference.py 成片 --envelope ... --archetype single-arc` → `render-profile.json`。

## 结果

时间线体检：`valid: true`，0 个错误。

- 状态判为“仅审片”：34 个素材都未清权。这和项目 brief 自己的结论一致（“审片版，不是可发布版”）。
- 没有黑底文字卡；配乐整首一次挂载；旁白与原话不重叠。
- 语音覆盖 0.595，低于单人逆转参考区间 0.66–0.98；≥8 秒的纯音乐段 3 段，参考是 0–2 段。原因可以确认：2022 世界杯那段“旁白停下，让音乐和画面走”约 29 秒，这是多声部片的峰值手法，用在单人片上是有意的。

## 结论

结构、叙事位置和剪辑节奏都在参考区间里；偏出的是混音动态。若要让 2022 段真正“扬”起来，方向是降低开场和“输”那段的配乐与现场声、把“结束了”前后的安静拉长到能听出来，而不是把峰推得更响。

这是机器测量。v1.0 还没有人从头到尾看过、听过；这条判断要由真人听感确认后才算数。
