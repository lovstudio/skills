# 来源与保真契约

## 来源快照

每篇转载至少记录：公开 URL、标题、来源账号、抓取时间、可见正文 SHA-256、原图数量与每张图的来源 URL/SHA-256。只有聊天线索时，WDB 的数据库、表和 rowid 作为内部证据保存，不进入公开稿。

## 可见正文

使用浏览器最终可见正文或公开页面正文节点，不从搜索摘要、聊天卡片摘要或旧缓存重建。归一化散列只折叠 Unicode 空白，不改标点、大小写、数字和字序。来源块在本地稿和远端回读中应能被唯一选择。

## 允许的机械净化

只有同时满足下列条件，才可删除微信页面运行态节点：

- 节点不贡献可见文字；
- 节点不承载正文图片或可见背景图；
- 清理前后归一化可见文字一致；
- 图片数量、顺序和来源账本一致；
- 删除项被记录，例如隐藏 SVG 动画或平台占位节点。

不得借“兼容”之名删除段落、折叠名单、重写图注或改变合作方视觉资产。

## 冻结区

来源正文必须位于唯一的 `data-repost-source="true"` 节点，并保留 `data-source-account`。发布方文字只能位于冻结区外。平台净化外链 `<a>` 或 `position` 时，允许去包装但必须保持标签序列、class、其余 CSS 与可见文字；差异写入远端收据。

## 图片账本

原图默认原样保存与按序复用。懒加载的 `data-src`、CSS background 和正文 `<img>` 都需枚举；下载失败不能静默写成“图片已完整保留”。生成式重绘不能替代合作方海报、Logo、照片或信息图。
