# Acceptance Checklist

集成完成后逐项核对；任何一项不满足都应回到 `integrate` / `verify` 修正后复测。

## 渲染一致性

- [ ] `verify` 输出 `OK`，且 `out == node × scale` 两个维度都精确相等。
- [ ] 表格、`white-space: nowrap` 单元格、flex 头部在导出图中没有多出换行。
- [ ] 内联 SVG、CSS 变量（`--surface` 等）在导出图中正确着色。

## 分辨率

- [ ] `scale` 使输出宽度 ≥ 1200px（默认 760 × 2 = 1520），适合网络传播。
- [ ] 导出文件为 PNG，尺寸与页面内容一致，无空白页边。

## 主题与视觉

- [ ] 按钮/错误条在浅色与暗色页面都可读，不遮挡主体内容。
- [ ] 按钮不泄漏产品意图（文案仅「导出图片」），样式克制、无 emoji。
- [ ] `#capture` 背景色与页面 `body` 一致（暗色页面导出不为白底）。

## 错误处理

- [ ] 截图失败时出现可复制的错误提示，含 `error.stack` 便于 debug。
- [ ] 库未加载时给出明确提示，而不是静默失败。

## 自包含与可移植

- [ ] `modern-screenshot` 内联，离线打开也可截图。
- [ ] 不引入 CDN 依赖；不硬编码私密路径或品牌数据。
- [ ] 目标页原有结构、脚本、样式未被破坏（diff 确认仅新增注入块）。

## 证据

- [ ] 记录真实输入文件、`integrate` 命令、`verify` 输出、产出路径。
- [ ] 不虚构截图、分数、延迟收益或尚未发生的集成。
